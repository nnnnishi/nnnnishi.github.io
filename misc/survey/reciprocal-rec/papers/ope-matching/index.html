Off-Policy Evaluation and Learning for Matching Markets

マッチング市場のオフ方策評価と学習

  • Yudai HayashiWantedly, inc.
  • Shuhei GodaIndependent Researcher
  • Yuta SaitoCornell University

求人サービスで新しい推薦の方策を A/B テストの前に評価したいとき、過去のログから成果を推定するオフ方策評価（OPE）が使われる。しかしマッチは、企業がスカウトを送り、求職者が返信したときにだけ起こるまれな出来事なので、マッチを直接重みづける IPS や DR の推定値は大きくぶれる。Hayashi らは、1 段目のスカウトの記録に重みをかけ、2 段目の返信の確率は回帰モデルで補う推定量 DiPS と DPR を提案した。Wantedly の A/B テストのログでは、DPR の平均二乗誤差がほとんどの設定で最も小さかった。

背景

マッチはまれなので、マッチの記録に重みをかける標準の推定量は分散が大きい

推薦のオフ方策評価では、過去の方策 \(\pi_0\) のログから新しい方策 \(\pi\) の成果を推定する。成果の回帰モデルを使う DM は分散が小さいが偏りが大きく、方策の確率の比で重みづける IPS は偏りがない代わりに分散が大きい。DR は両者を組み合わせる。

双方向市場では成果（マッチ）が両側の反応の積で決まり、とても疎になる。論文は、マッチングの市場のオフ方策評価と学習を定式化したのはこの論文が初めてだとしている。双方向市場の推薦の手法そのもの（Su ら、Tomita らなど）は関連研究として引用しているが、目的は推薦の手法ではなく評価にあると述べる。

問題設定

企業に求職者を推薦し、企業がスカウトを送り、求職者が返信したらマッチになる

企業 \(c \in C\) に方策 \(\pi(j \mid c)\) で求職者 \(j \in J\) を推薦する。1 段目の報酬 \(s\) は企業がスカウトを送ったか、2 段目の報酬 \(r\) は求職者が返信したかで、マッチは \(m = s \cdot r\) である。\(q_s(c,j) = \mathbb{E}[s \mid c,j]\)、\(q_r(c,j) = \mathbb{E}[r \mid c,j,s=1]\) とおくと、方策の価値（期待マッチ数）は次のように書ける（式 1）。

\[ V(\pi) = \frac{1}{|C|} \sum_{c \in C} \sum_{j \in J} \pi(j \mid c)\, q_s(c,j)\, q_r(c,j) \]

IPS は \(\hat V_{\mathrm{IPS}} = \frac{1}{|C|} \sum_c \frac{\pi(j_c \mid c)}{\pi_0(j_c \mid c)} m_c\) である（式 7）。分散には重みの 2 乗とマッチのばらつき \(\sigma_m^2\) の積が入る（命題 2.1）。ベルヌーイの報酬では分散と平均の比が \(1 - q\) なので、マッチが疎なほど平均に対してばらつきが大きくなる。DR も同じ項を持つので、疎なマッチの影響を受ける（命題 2.2）。

手法

重みは 1 段目のスカウトにだけかけ、2 段目の返信は回帰モデルの予測で置き換える

DiPS（Direct and Propensity Score）は、スカウトの記録 \(s_c\) に重みをかけ、返信の確率は回帰モデル \(\hat q_r\) で補う（式 12）。

\[ \hat V_{\mathrm{DiPS}}(\pi; \mathcal{D}) = \frac{1}{|C|} \sum_{c \in C} \frac{\pi(j_c \mid c)}{\pi_0(j_c \mid c)}\, s_c\, \hat q_r(c, j_c) \]

DPR（Direct, Propensity, and doubly Robust）は、これにマッチの回帰モデル \(\hat q_m\) による DR の補正項を加える（式 17）。\(\hat q_m = 0\) とおくと DiPS に戻る。

\[ \hat V_{\mathrm{DPR}}(\pi; \mathcal{D}) = \frac{1}{|C|} \sum_{c \in C} \Big\{ \frac{\pi(j_c \mid c)}{\pi_0(j_c \mid c)} \big( s_c\, \hat q_r(c, j_c) - \hat q_m(c, j_c) \big) + \mathbb{E}_{\pi(j \mid c)}\big[\hat q_m(c, j)\big] \Big\} \]
  • 偏り：DiPS の偏りは \(\frac{1}{|C|} \sum_c \mathbb{E}_\pi[q_s \cdot (\hat q_r - q_r)]\) で、2 段目のモデルの誤差だけから来る（定理 4.1）。DPR の偏りは DiPS と同じである（定理 4.5）。\(\pi_0\) を推定した場合の偏りも示している（定理 4.2、C.1）。
  • 分散：\(\hat q_r \le q_r\) がすべての組で成り立てば、IPS と DiPS の分散の差は \(\frac{1}{|C|^2} \sum_c \mathbb{E}_\pi[w^2 q_s \sigma_r^2] \ge 0\) 以上になる（定理 4.4）。DPR の分散は 2 段目のモデルの誤差に依存し、モデルが正確なら DiPS より小さくなる（定理 4.6）。
  • オフ方策学習：方策の勾配も同じ形で推定し（DiPS-PG、DPR-PG）、勾配上昇法で方策を学習する。付録では Switch-DR と MIPS（Saito と Joachims 2022）にも同じ考え方を広げている。
実験の結果

合成データでも実データでも、DiPS と DPR は少しの偏りと引き換えに分散を大きく減らし、平均二乗誤差を下げた

合成データでは、企業と求職者の 10 次元の特徴量からスカウトと返信の確率を作り、企業の数、求職者の数（行動の数）、報酬の疎らさを変えて比べた。DiPS と DPR は IPS や DR よりずっと分散が小さく、偏りはわずかに大きいだけで、ほとんどの設定で平均二乗誤差が最も小さかった（論文 図2〜4）。方策の学習でも、DPR-PG と DiPS-PG の方策の価値がほとんどの場合で最も高かった（論文 図7）。

実データは、求人マッチングのサービス Wantedly Visit（登録者 400 万人以上、企業 4 万社以上）のスカウトの推薦の A/B テストのログである。

ログの方策は再現できないので、\(\pi_0\) と \(\pi\) は勾配ブースティングで推定した。企業を抜き出して 20 回繰り返すと、DPR はほとんどの設定でベースラインより平均二乗誤差がはっきり小さかった（論文 図5）。一方、方策の良し悪しの判定を誤る確率（ErrorRate）は DiPS と IPS のほうが DPR や DR より低かった。論文は、IPS が方策の価値を過大に推定しやすいためだと説明している（論文 図6）。返信とマッチの回帰モデルは真の確率を 23〜53% 過小に予測しており（論文 Table 3）、これが偏りに影響すると述べる。

双方向市場の推薦の研究の中での位置づけ

両側の反応の積で決まるマッチの疎らさに合わせて、オフ方策評価の推定量を作り直した

  • 目的：ログから新しい推薦の方策の期待マッチ数を推定し、方策を学習する。
  • 解き方：1 段目の報酬に重要度の重み、2 段目に回帰モデルを使う推定量（DiPS）と、それに DR の補正を加えた推定量（DPR）。
  • 限界：2 段目のモデルが誤っていると偏りが出る。実データでは方策の確率を推定する必要があった。平均二乗誤差と方策の判定の誤りが一致しないことがある。論文には限界と今後の課題をまとめた節はない。
  • つながり：双方向市場の評価の偏りを扱う研究には、両側の表示位置の偏りを重みで補正する Oh ら（2023）の評価指標もある（この論文は引用していない）。
