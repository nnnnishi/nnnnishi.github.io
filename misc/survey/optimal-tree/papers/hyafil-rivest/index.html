Information Processing Letters · Vol. 5 · 1976

Constructing Optimal Binary Decision Trees is NP-Complete

最適な二分決定木を作る問題は NP 完全である

  • Laurent HyafilIRIA – Laboria, Rocquencourt, France
  • Ronald L. RivestDept. of Electrical Engineering and Computer Science, MIT

有限個の対象のうち未知の 1 つを、真か偽を返すテストを順に当てて特定する場面を考える。そのための二分決定木のうち、特定に要するテストの回数の合計（平均）が最小のものを作る問題は NP 完全である。証明は、3 要素の集合による完全被覆の問題を決定木の問題に置き換え、最適な木が必ずその完全被覆を根からの 1 本の鎖として含むことを、最小のコストの漸化式で示す。

  • NP 完全与えられたテストの集合で、コスト（根から各対象までのテストの回数の合計）が \(w\) 以下の決定木があるかを判定する問題 DT が NP 完全である。
  • 3 ページの証明3 次元マッチング → 3 要素の集合による完全被覆（EC3）→ DT と帰着をつなぐ。
  • 最悪の回数でも同じ結論の節で、平均ではなく最悪の場合のテストの回数をコストにしても、同じ構成で NP 完全になると述べている。
問題設定

テストを当てて対象を 1 つに特定する二分決定木の、テストの回数の合計を最小にする

対象の有限集合 \(X = \{x_1, \dots, x_n\}\) と、テストの有限集合 \(\mathcal T = \{T_1, \dots, T_t\}\) が与えられる。各テストは各対象に真か偽を返し、\(T_i\) は真になる対象の集合とも見なせる。未知の対象を特定する手続きは二分決定木で、根と内部ノードにテストを置き、偽なら左、真なら右に進み、終端のノードが対象を 1 つ名指しする。

対象 \(x_i\) を特定するのに必要なテストの回数を、根から \(x_i\) の終端までの道の長さ \(p(x_i)\) とする。木のコストはその合計 \(\sum_{x_i \in X} p(x_i)\)（外部道長）で、対象が等確率ならテストの回数の期待値の \(n\) 倍にあたる。決定木の問題 \(\mathrm{DT}(\mathcal T, X, w)\) は、コストが \(w\) 以下の決定木があるかを判定する問題である。論文は、決定表のコンパイルなど多くの同定の問題がこの形をとると述べ、テストごとに費用を付けた一般化も当然 NP 完全になるとしている。

背景

効率のよい構成法が多く研究されてきたが、P ≠ NP なら多項式時間のアルゴリズムはない

最適な二分決定木を効率よく作るアルゴリズムは、決定表の変換などに関連して多く研究されてきた。論文は、証明は比較的簡単だが、この結果の重要さはそれまでの研究の多さで測れると述べる。P ≠ NP を仮定すれば効率のよいアルゴリズムは存在しないと予想でき、最適に近い決定木を作る効率のよい発見的な方法（ヒューリスティック）を探す動機になる、というのが論文の主張である。

証明 1　帰着の流れ

3 次元マッチングから 3 要素の完全被覆へ、さらに決定木の問題へと帰着する

DT が NP に属するのは明らかで、非決定的なチューリング機械が木を推測し、そのコストが \(w\) 以下かを確かめればよい。NP 困難であることは、次の問題 EC3 を DT に帰着して示す。

  • EC3：集合 \(X\) と、ちょうど 3 要素の部分集合の族 \(\mathcal T\) が与えられたとき、\(\mathcal T\) から互いに素な部分集合を選んで \(X\) をちょうど覆えるか（3 要素の集合による完全被覆）。
  • 3DM ∝ EC3：3 次元マッチングは Karp が NP 完全であることを示した問題で、3 つの集合 \(B_1, B_2, B_3\) から 1 つずつ要素をとった三つ組の集合 \(U\) を、和集合 \(B_1 \cup B_2 \cup B_3\) 上の 3 要素の部分集合と見れば EC3 になる。よって EC3 も NP 完全である。

EC3 の問題 \((\mathcal T, X)\) から、DT の問題を次のように作る。\(X\) にない 3 つの要素 \(a, b, c\) を足し、テストには元の三つ組に加えて、すべての要素の 1 要素の集合を足す。

\[ X' = X \cup \{a, b, c\}, \qquad \mathcal T' = \mathcal T \cup \big\{ \{x\} : x \in X' \big\} \]
証明 2　最適な木の形

大きな集合では根で 3 要素のテストを選ぶのが最適なので、最適な木は完全被覆の鎖を含む

1 要素、2 要素、3 要素のすべての部分集合をテストに使えるときの、\(n\) 要素の集合に対する最小のコストを \(f(n)\) とする。根で \(i\) 要素のテストを選ぶと、木は \(i\) 要素と \(n - i\) 要素の部分木に分かれ、すべての対象の道が 1 ずつ長くなる。

\[ f(n) = \min_{1 \le i \le 3} \big[ f(n - i) + f(i) + n \big] \quad (n \ge 4), \qquad f(1), \dots, f(8) = 0, 2, 5, 8, 12, 16, 20, 25 \]

\(n - 2 \le m \le n - 1\) で \(f(m) - f(m-1) > 3\) なら、最小にするには \(i = 3\) を選ぶ必要があり、そのとき \(f(n) - f(n-1) = f(n-3) - f(n-4) + 1 > 3\) も成り立つ。よって \(n \ge 7\) では、根で 3 要素の集合を選ぶのが最適になる。下の図で \(n\) を動かすと、漸化式で選ばれる \(i\) を確かめられる。

論文の漸化式（\(f(1)=0, f(2)=2, f(3)=5\) から）で解説者が計算した値。\(n \le 8\) は論文の Table 1 と一致する。

\(\mathcal T'\) にはすべての 2 要素、3 要素の集合があるわけではないので、\(f(|X'|)\) はこの問題のコストの下限になる（解説者の補足）。図1 の形の木、つまり完全被覆をなす三つ組 \(T_{i_1}, \dots, T_{i_k}\) を根から鎖状に並べ、各三つ組の中を 1 要素のテストで見分け、最後に \(a, b, c\) を残す木は、コスト \(f(|X'|)\) をちょうど達成するので最適である。逆に最適な木は、十分大きな部分木の根がどれも \(X\) の 3 要素の部分集合のテストでなければならないので、必ず EC3 の解を含む。したがって EC3 は DT に帰着でき、DT は NP 完全である。

結論

最適な二分決定木の構成はおそらく多項式時間では解けず、当面はよいヒューリスティックが最善の策になる

論文は、最適な二分決定木の構成は NP 完全であり、P ≠ NP がおそらく正しいとすれば、多項式時間では解けない可能性が高いと結論する。対象に確率を与える場合や、平均ではなく最悪の場合のテストの回数をコストにする場合など、関連するコストの測り方でも、同じ構成で NP 完全になる。そのため、最適に近い二分決定木を作るよいヒューリスティックが、近い将来この問題に対する最善の解決策になるだろうと述べている。

最適決定木の研究の中での位置づけ

最適な決定木の研究が計算量の根拠として引く出発点だが、証明された問題は対象の同定である

  • 解く問題：各終端が対象を 1 つだけ名指しする同定の木で、テストの回数の合計（外部道長）を最小にする。テストは \(X\) の任意の部分集合でよく、特徴量としきい値の形には限らない。
  • 結果：判定版 DT は NP 完全。最悪の場合のテストの回数をコストにしても同じ。

（解説者の注）CART の論文や OCT、BinOCT、Verwer & Zhang（2017）、Aghaei らは、最適な決定木を学習する問題が NP 困難（NP 完全）である根拠としてこの論文を引いている。ただし、これらが解くのはラベルつきのデータの誤分類を深さの上限のもとで最小にする問題で、この論文が証明した「対象をすべて見分ける木の外部道長の最小化」とは問題の形が違う。論文自身が予想した「ヒューリスティックが最善の策」という見通しは、ソルバーの進歩とともに見直されていった（OCT の論文の導入を参照）。
