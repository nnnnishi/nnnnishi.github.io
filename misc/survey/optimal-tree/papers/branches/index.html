Branches: A Fast Dynamic Programming and Branch & Bound Algorithm for Optimal Decision Trees

Branches：AND/OR グラフ探索で最適な疎な決定木を速く求める

  • Ayman ChaoukiLIX, École Polytechnique, IP Paris
  • Jesse ReadLIX, École Polytechnique, IP Paris
  • Albert BifetUniversity of Waikato / Télécom Paris

背景

動的計画法と分枝限定の主流は深さ優先探索で、深い木と最大深さの設定に弱い

最適な決定木を求める近年の解法は、項目集合の格子を探索する DL8 の系譜（DL8.5、MurTree、STreeD）に代表される。これらは深さ優先探索（DFS）を基本としており、メモリの使い方では経済的だが、有望でない領域を長く探索しがちで、深い木では効率が落ちる。また、探索を打ち切るために最大深さをあらかじめ決めておく必要がある。

一方、最良優先探索（BFS）は有望な候補から広げられるため速く、最大深さも不要だが、保持する候補が増えてメモリを大量に消費する。GOSDT など BFS 系の既存実装は、問題の AND/OR 構造を活かし切れていない、と論文は指摘する。

問題

最良優先探索を実用にするには、AND/OR 構造に合った探索と強い下界が要る

決定木の部分問題は「分岐を選ぶ（OR）」と「左右の部分木を両方解く（AND）」の組み合わせであり、AND/OR グラフとして自然に表せる。この構造のうえでは、古典的な AO* アルゴリズムが最良優先探索の枠組みになる。課題は、AO* を決定木のスパース性（誤分類と分岐数のトレードオフ）の問題に正しく乗せることと、探索を絞るための良い下界（ヒューリスティクス）を用意することである。

提案手法

Branches は AND/OR グラフ上の AO* 探索に Purification Bound という解析的下界を組み合わせる

Branches は、スパースな最適決定木の問題を AND/OR グラフ探索として定式化し、AO* 型のアルゴリズムで解く。各分岐（部分データ）には Purification Bound と呼ぶ解析的な下界を与え、有望な分岐から優先的に展開する。分岐単位のキャッシュも備える。終了すれば最適解が得られることが証明されており、終了までに評価する分岐の数についても、従来研究より小さい複雑さの上界が示されている。

もう1つの特徴は、特徴量が二値でなくてもよい点である。順序符号化された特徴量をそのまま多分岐の分岐として扱えるため、二値化で特徴量が膨らむことによる探索の増大を避けられる。制限時間に達した場合は、その時点の最良の木を返す anytime 性も持つ。

実験

UCI の11データで GOSDT の大半を上回り、順序符号化では全実験が制限時間内に終わった

実験は UCI の11データセットで、制限時間は5分、深さ優先系（MurTree、STreeD）の最大深さは20、最良優先系（GOSDT、Branches）は深さ無制限という条件である。Branches は GOSDT との比較で、car-eval-f と balance-f を除くすべての実験で上回り、両方が時間切れになった場合でもより良い木を返した。STreeD が勝ったのは mushroom 系の2件だけで、その場合も Branches は anytime の木として真の最適木を返していた。

順序符号化の実験では、どのデータでも制限時間（300秒）内に終わり、最も遅い lymph でも12.3秒だった。二値化を経由しないことで、探索空間そのものが小さくなる効果が大きいと論文は分析している。

位置づけと限界

最良優先への転換と非二値特徴量の扱いが新しいが、現時点ではプレプリントである

このリストの動的計画法・分枝限定の系統は、DL8.5 や MurTree など深さ優先が中心だった。Branches は AO* による最良優先への転換と、順序特徴量への直接対応という2点で、その流れに対する新しい提案になっている。深さの上限を決めずに済む点も、実務では地味に大きい。

限界として、現時点では査読付きの発表先が確認できていないプレプリントであること、最良優先探索ゆえのメモリ消費が弱点として残ること（著者ら自身が深さ優先とのハイブリッドを今後の課題に挙げている）、実装が Python で C++ 化は今後の課題とされていることが挙げられる。
