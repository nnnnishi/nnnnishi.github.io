Free Lunch! Retrospective Uplift Modeling for Dynamic Promotions Recommendation within ROI Constraints

ROI 制約のもとで特典の配布先を動的に選ぶ、振り返り型のアップリフトモデリング

  • Dmitri GoldenbergBooking.com, Tel Aviv, Israel
  • Javier AlbertBooking.com, Tel Aviv, Israel
  • Lucas BernardiBooking.com, Amsterdam, Netherlands
  • Pablo EstevezBooking.com, Amsterdam, Netherlands

宿泊予約サイトの無料特典は予約を増やすが、全員に出すと費用が売上の増分を上回り、ROI が負になることがある。この論文は損失の増分の合計を 0 以下に保ちながら予約の増分を最大にする配布先の選び方をナップザック問題として定式化し、その順位を予約した顧客のデータだけで推定する「振り返り推定」を提案する。Booking.com のオンライン実験では、ROI を正に保ったまま、全員に配った場合の効果の 66〜74% を得た。

背景

無料特典は予約を増やしたが、全員に出すと ROI が負になった

オンライン旅行サイトは部屋のアップグレード、無料の食事、送迎などの特典を予約のきっかけとして出している。特典は顧客に価値を与える一方で費用がかかるため、続けるには費用を売上の増分で賄う必要がある。論文は ROI を次のように定め、キャンペーンを続ける条件として \(ROI \ge 0\) のような下限を置く。

\[ ROI = \frac{\Delta \mathit{Revenue} - \Delta \mathit{Investment}}{\Delta \mathit{Investment}} \]

題名の例でいえば、予約の特典として昼食を無料にする施策は、予約率の増分で昼食代を賄えるときにだけ続けられる。Booking.com が全員に無料特典を出す A/B テストを行ったところ、予約への平均処置効果（ATE）ははっきり正だったが、ROI は負で、特典を出し続けられる水準ではなかった。そこで、特典を出す相手を絞ることになる。

相手を絞る方法として一般的なのは、特典があるときだけ予約する顧客をアップリフトモデルで見分けることである。ただし論文は、学習データの大半が購入意図のない訪問で占められるため推定のばらつきが大きいこと、また過去のデータで作った解は季節性などの長期的な変化に追いつけず、動的な較正が要ることを課題に挙げている。

定式化

ROI ≥ 0 の制約は損失の増分の合計を 0 以下に保つことと同じで、配布先の選択はナップザック問題になる

予約を \(Y\)、予約に伴う売上を \(R\)、特典の費用を \(C\) とし、予約がなければ売上も費用も生じないと仮定する。それぞれの条件付き平均処置効果を \(CATE_Y(x)\)、\(CATE_R(x)\)、\(CATE_C(x)\) と書き、損失 \(\mathcal{L} = C - R\) の増分を \(CATE_{\mathcal{L}}(x) = CATE_C(x) - CATE_R(x)\) とする。目的は予約の増分の合計を最大にしつつ、損失の増分の合計を 0 以下に保つことである。

\[ \max_{z}\; \sum_{i\in U} z_i\, {\color{#1D4ED8}{CATE_Y(x_i)}} \quad \text{s.t.}\quad \sum_{i\in U} z_i\, {\color{#C2410C}{CATE_{\mathcal{L}}(x_i)}} \le 0,\qquad z_i\in\{0,1\} \]

売上は増えた予約からしか生まれないので、\(CATE_Y \le 0\) なら \(CATE_{\mathcal{L}} \ge 0\) であり、こうした顧客には配らない。予約の増分が正で損失の増分が 0 以下の顧客は、予約も利益も増やすので配る。この人たちが生む利益が、残りの顧客に回せる損失の上限になる。残る \(CATE_Y > 0\) かつ \(CATE_{\mathcal{L}} > 0\) の顧客については、通常の 0-1 ナップザック問題になる。

論文は分数ナップザック問題の貪欲法にならって顧客を \(CATE_Y / CATE_{\mathcal{L}}\) の大きい順に並べ、制約を満たせなくなるまで順に配る近似をとる。最後に配った顧客の比を閾値 \(\theta^*\) とすれば、配布ルールは \(g(x) = CATE_Y(x)/CATE_{\mathcal{L}}(x) \ge \theta^*\) になる。こうして問題はこの比と、\(CATE_Y\)、\(CATE_{\mathcal{L}}\) の符号を学習することに帰着する。

手法

振り返り推定は、予約した顧客のうち特典を受けた人の割合から順位を求める

無作為化実験のデータがあれば、潜在的結果の期待値は群ごとの条件付き期待値で書ける。予約 1 件あたりの費用を \(\hat C(x) = \mathbb{E}[C\mid x, T{=}1, Y{=}1]\)、売上を \(\hat R_t(x) = \mathbb{E}[R\mid x, T{=}t, Y{=}1]\) とすると、順位に使う比は次のように書ける。

\[ \frac{CATE_Y(x)}{CATE_{\mathcal{L}}(x)} = \frac{\Pr(Y{=}1\mid x,T{=}1) - \Pr(Y{=}1\mid x,T{=}0)}{\Pr(Y{=}1\mid x,T{=}1)\,[\hat C(x) - \hat R_1(x)] + \Pr(Y{=}1\mid x,T{=}0)\,\hat R_0(x)} \]

この式の確率と期待値をすべて別々のモデルで推定する方法を、論文は Fractional Approximation と呼ぶ。提案する振り返り推定（Retrospective Estimation）は、ベイズの定理で予約確率を書き換える。実験では特典を出す確率を 0.5 にしているので、処置群と対照群の予約確率の比は、予約した顧客のうち特典を受けていた人の割合 \(S(x) = \Pr(T{=}1\mid x, Y{=}1)\) だけで表せる。

\[ \frac{\Pr(Y{=}1\mid x,T{=}1)}{\Pr(Y{=}1\mid x,T{=}0)} = \frac{S(x)}{1-S(x)}, \qquad \frac{CATE_Y(x)}{CATE_{\mathcal{L}}(x)} = \frac{2S(x)-1}{S(x)\,[\hat C(x) - \hat R_1(x)] + [1-S(x)]\,\hat R_0(x)} \]

予約の増分の符号は \(S(x) - 0.5\) の符号と一致する。特典に効果がなければ予約した人の半分が処置群になり、半分を超えれば特典で予約が増えたことになる。\(S(x)\)、\(\hat R_t(x)\)、\(\hat C(x)\) はどれも予約した顧客のデータだけで推定できる。このため、ほとんど購入しないスクレイパーやクローラーを含む訪問全体のノイズに強く、クラスの不均衡も起きにくい。必要な取引データも少なくて済み、集めやすい。

さらに、予約 1 件あたりの売上と費用が \(x\) によらず、売上が処置によらない（\(\hat R_t(x) = \hat R\)、\(\hat C(x) = \hat C\)）と仮定すると、\(CATE_Y > 0\) は \(S(x) > 0.5\)、\(CATE_{\mathcal{L}} > 0\) は \(S(x) < \hat R/(2\hat R - \hat C)\) と同じになる。論文はこうして \(S(x)\) をモデル化するだけで貪欲法の問題を解けると述べる。この仮定のもとで比を \(S\) で微分すると \(\hat C\) を分母の 2 乗で割った正の値になるので、分母が正の範囲では比の順位と \(S(x)\) の順位が一致する（解説者の注）。

動的較正

運用中は、配布割合と ROI の関係を指数曲線で当て直し、ROI が 0 になる閾値に更新する

オフラインで決めた閾値は、手元の標本に対する最適な割り当てにすぎない。運用中はトラフィックの分布が変わり、最適な閾値もずれる。論文は特典を出す割合 \(Q_\theta\) と ROI の間に単調な非線形の関係を仮定し、それを指数曲線で近似する。

\[ \widehat{ROI}(Q) = a\,e^{bQ} + c \]

係数 \(a, b, c\) は Levenberg–Marquardt 法による最小二乗で当てはめ、\(\widehat{ROI}(Q_{\theta^*}) = 0\) となる \(\theta^*\) を新しい閾値にする。決めた期間ごとに当て直すので、過去のデータと直近のデータの両方を ROI の推定に取り込める。

実験の設定

全員配布の A/B テストで集めた 1 億件超の訪問データで、4 つの手法を比べた

学習データは全員配布の A/B テストで集めた 1 億件を超える訪問で、顧客の現在と過去の検索や取引がひもづいている。各訪問には予約の有無と、あれば売上と特典の費用がつく。どの手法も XGBoost を下敷きにし、時系列に沿った交差検証で調整した。

  • Two-Models：処置群と対照群で別々にモデルを作り、その差をとる。
  • Transformed Outcome：\(CATE_Y(x)\) を 1 つのモデルで直接推定する。
  • Fractional Approximation：比 \(CATE_Y/CATE_{\mathcal{L}}\) の各項を別々のモデルで推定する。
  • Retrospective Estimation：予約した顧客だけで \(S(x)\) などを推定する（提案手法）。

前の 2 つは比の分子だけを推定するので、制約のない問題の基準として使われる。評価には上位から配ったときの効果の累積を描く Qini 曲線と、その面積 AUUC に加えて、論文が提案する Qini-ROI 曲線を使う。これは上位から配ったときの ROI を描くもので、主な指標は ROI ≥ 0 を満たす範囲で得られる最大の効果（全員に配ったときの効果に対する割合）である。そのときの配布割合も合わせて見る。

実験の結果 1

オフライン評価では、振り返り推定が ROI ≥ 0 の範囲で全員配布時の 79.7% の効果を得た

AUUC が最も高かったのは Transformed Outcome（0.912）だったが、ROI が 0 になる点は配布割合 2.4% にあり、得られる効果は全員に配った場合の 38.6% にとどまった。Two-Models は制約がなければ最も大きな効果（109%）を見込めるものの、ROI ≥ 0 を満たす点が一つもなかった。Fractional Approximation は ROI ≥ 0 で最も多くの顧客（38%）に配れ、効果は 65.8% だった。

振り返り推定は効果が 79.7% と最も大きく、AUUC（0.806）と配布割合（31.4%）ではいずれも 2 位だった。なお、本文ではこの AUUC を 0.805 としている。論文は、従来のアップリフトモデルは費用を考えないため、AUUC では優れていても ROI に関わる指標では劣ったとまとめている。振り返り推定が Fractional Approximation を上回った理由については、学習データのノイズに強いためかもしれないと述べるにとどめている。

実験の結果 2

オンライン実験でも個別配布は ROI を正に保ち、閾値を期間ごとに較正すると効果が増えた

訪問者を無作為に 4 群に分け、同じ無料特典で 8 期間にわたって実験した。個別配布の 2 群には振り返り推定を使い、閾値はオフライン評価で 31.4% の顧客に配られるように決めた。D 群だけは決めた期間が終わるたびに閾値を較正し直した。

  • A 群（対照）：誰にも特典を出さない。各群の効果と ROI は A 群と比べて測る。
  • B 群（全員配布）：最初の実験と同じく、ROI は 0 を下回った。
  • C 群（個別配布、閾値固定）：ROI は一貫して高く、最終期で 0.36。累積の効果は B 群の 66% だった。
  • D 群（個別配布、動的較正）：ROI は最初の期間の 0.3 から終盤には 0.24 に落ち着いた。配布割合は 47% になり、効果は平均で B 群の 74%、最終期には 80% だった。

論文はこの結果から、個別配布によって ROI が負だったキャンペーンを、ROI を保ったまま大きな効果を出すキャンペーンに変えられたと結論づけている。また、動的な閾値の較正は制約を守ったまま効果を最大 20% 高めたと述べている。なお、各群の効果について信頼区間や検定の結果は示されていない。

予算制約つきアップリフトの中での位置づけ

予算額の代わりに ROI ≥ 0 を制約に置き、増分の比の順に配る

この論文が推定するのは、予約の増分 \(CATE_Y\) と損失の増分 \(CATE_{\mathcal{L}}\)（費用の増分 − 売上の増分）の比と、それぞれの符号である。振り返り推定ではこれを予約した顧客での \(S(x)\) と、予約 1 件あたりの売上 \(\hat R_t\) と費用 \(\hat C\) から組み立てる。費用は予約したときにだけ生じると仮定しており、予約がなければ売上も費用もない。処置は 1 種類の特典を出すか出さないかの二値である。

固定の予算額は置いていない。制約は「損失の増分の合計 ≤ 0」、つまり特典の費用の増分を売上の増分で賄うことで、\(CATE_{\mathcal{L}} < 0\) の顧客が生む利益が、ほかの顧客に回せる上限になる。論文は右辺を 0 に固定しており、ほかの値は扱っていない。

配布の順位は、論文自身が分数ナップザック問題の貪欲法として導いた \(CATE_Y / CATE_{\mathcal{L}}\) の大きい順である。これはナップザック問題の連続緩和で効用 ÷ 重みの順に詰める解き方そのものである。ただし、よくある「売上の増分 ÷ 費用の増分」の比とは違い、分子は予約件数の増分、分母は費用から売上の増分を引いた正味の損失になっている（解説者の注）。閾値はオフラインの標本で決め、運用中は ROI 曲線から決め直す。整数解との差は論じていない。
