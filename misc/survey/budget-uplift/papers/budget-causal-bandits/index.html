Budget-Constrained Causal Bandits: Bridging Uplift Modeling and Sequential Decision-Making

予算制約つき因果バンディット：アップリフトモデリングと逐次意思決定をつなぐ

  • Abhirami Pillai

予算つきの広告配信では、過去のランダム化実験のデータでアップリフトモデルを学習し、そのあと予算内で配る相手を最適化する2 段階のオフライン手順が標準である。この論文は過去データのない立ち上げ期にも使えるよう、効果の学習、探索、予算のペース配分を 1 人ずつの判断にまとめたBCCBを提案する。Criteo の実験では、過去データが 7,500 件未満のあいだはオフライン手順の平均が BCCB を上回らず、7,500 件以上になると有意に上回った。

  • 過去データ 7,500 件オフライン手順の転換数が BCCB を統計的に上回り始める件数（片側の対応のある t 検定で p = 0.043）。件数が増えるほど差は広がり、50,000 件では約 2.2 倍になった（Table 2）。
  • 63.5 対 35.7予算 8,000 ドルでの転換数（20 シードの平均）。予算のペース配分を加えた Uplifting Bandits を 78% 上回った。5 つの予算すべてで、4 つのオンライン手法を上回った（p < 0.001、Table 1）。
  • 標準偏差 16.2 対 37.8〜58.7予算 5,000 ドルでの、シード間の転換数のばらつき。BCCB の標準偏差は過去データの件数を変えたオフライン手順の 2.3〜3.6 分の 1 だった（Table 5）。
背景

予算つきの配布は過去データで学習してから最適化するのが標準だが、立ち上げ期にはそのデータがない

広告を見せたときの反応は人によって違う。広告を見て購入する気になる人もいれば、広告がなくても購入する人や、広告の影響を受けない人もいる。そこで、一人ひとりへの処置効果（アップリフト）を推定し、予算の範囲で効果の大きい人に配る。標準的なのは、過去のランダム化実験のデータでアップリフトモデルを学習し、その推定値を多選択ナップザック問題などの最適化に入れる2 段階のオフライン手順である。予測と最適化の目的がずれるという弱点に対しては、E3IR、Bi-DFCL、DHCL、LBCF のような手法が提案されてきた。

論文は、これらの手法がどれも十分な過去データを前提にしていると指摘する。新しいキャンペーン、新しい市場や顧客層では過去データがないか、あっても配信先の集団を代表しない。一方、予算つきのバンディットは 1 回ずつ判断しながら学ぶが、利用者ごとの因果効果の違いはモデルに入れていない。この論文は両者をつなぎ、過去データなしで効果を学びながら予算を使う方法を提案する。

問題設定

予算を期待値の制約に緩めると、最適な方策は「1 ドルあたりの効果がしきい値を超えたら配る」になる

利用者は 1 人ずつ \(T\) 回やってくる。時刻 \(t\) には特徴 \(\mathbf{x}_t\) と、その人に広告を出す費用 \(c_t > 0\) が分かり、広告を出す（\(a_t = 1\)）か出さないか（\(a_t = 0\)）を決める。結果 \(Y_t\) は購入の有無（0 か 1）で、処置効果は \(\tau(\mathbf{x}_t) = \mathbb{E}[Y_t(1) - Y_t(0) \mid \mathbf{x}_t]\) である。広告を出さなくても起きる購入は方策によらないので、目的は広告が生んだ増分の購入を予算の範囲で最大にすることになる。

\[ \max_{\pi}\ \mathbb{E}\Big[\sum_{t=1}^{T} a_t\,\tau(\mathbf{x}_t)\Big] \quad \text{s.t.} \quad \sum_{t=1}^{T} a_t\,c_t \le B \]

予算制約に双対変数 \(\lambda \ge 0\) を置いてラグランジュ緩和すると、目的は時刻ごとに分かれ、各時刻の判断は次のしきい値ルールになる。\(\lambda\) は予算 1 ドルの「影の価格」にあたる。

\[ a_t^{*}(\lambda) = \mathbb{I}\Big[\,\frac{\tau(\mathbf{x}_t)}{c_t} > \lambda\,\Big] \]

Proposition 1 は、利用者が i.i.d. に到着し、無交絡と正値性が成り立つとき、予算を期待値の制約 \(\mathbb{E}[\sum_t a_t c_t] \le B\) に緩めた問題では、このルールを最適な \(\lambda^{*}\) で使う方策が最適になることを示す。どの実現でも予算を超えないという本来の制約は、残り予算より高い人には配らない、という別のチェックで守る。論文は、有限の期間で本来の制約のもとでもこの方策が最適だとは主張していない。

実際には \(\tau\) も \(\lambda^{*}\) も分からない。過去データがないので \(\tau\) は配りながら学ぶ必要があり、探索にも予算がかかる（論文の P1）。\(\lambda^{*}\) は \(\tau\) と \(c\) の分布で決まるので、キャンペーン中に推定し続ける必要がある。低すぎれば予算を早く使い切り、高すぎれば予算を余らせる（P2）。

手法

BCCB は効果の推定値に探索のゆらぎを足し、残り予算に応じて動かすしきい値と比べる

BCCB（Budget-Constrained Causal Bandits）は、次の 3 つを 1 つの判定ルールにまとめる。

  • 効果のオンライン推定（P1）：広告を出した人の購入確率 \(\hat f_1(\mathbf{x})\) と出さなかった人の購入確率 \(\hat f_0(\mathbf{x})\) を、2 つのロジスティック回帰で別々に推定し（two-model）、確率的勾配法で逐次更新する。効果の推定値は \(\hat\tau(\mathbf{x}_t) = \hat f_1(\mathbf{x}_t) - \hat f_0(\mathbf{x}_t)\)。処置群と対照群の観測がそれぞれ \(W = 50\) 件たまるまでは、小さな正の値 \(\hat\tau_0 = 0.002\) を使い、初めのうちは配る判断になりやすくして探索を促す。
  • 探索のゆらぎ：処置群と対照群の全体の購入率にベータ事後分布を置き、毎回それぞれから \(\theta_t,\ \theta_t^{(c)}\) を抜き出して \(b_t = \eta\,(\theta_t - \theta_t^{(c)})\) を足す。これは個人の効果の事後サンプルではなく、集団全体の不確かさに応じたゆらぎで、事後分布が絞られるにつれて小さくなる。論文は \(\eta = 0.1\) を使う。
  • 予算のペース配分（P2）：残り予算の割合を残り時間の割合で割った \(\mathrm{pace}_t\) を計算し、しきい値を \(\hat\lambda_t = \lambda / \max(\mathrm{pace}_t,\ 0.1)\) とする。予算が余り気味（\(\mathrm{pace}_t > 1\)）ならしきい値が下がって多く配り、使いすぎ（\(\mathrm{pace}_t < 1\)）なら上がって絞る。基準値は \(\lambda = 10^{-3}\)。
\[ \mathrm{pace}_t = \frac{B_t / B_0}{\max\{(T-t)/T,\ 0.01\}}, \qquad a_t = \mathbb{I}\Big[\,\frac{\hat\tau(\mathbf{x}_t) + b_t}{c_t} > \hat\lambda_t\,\Big] \]

費用 \(c_t\) が残り予算 \(B_t\) を超える人には配らない。配った人の結果は \(\hat f_1\) と処置群の事後分布の更新に、配らなかった人の結果は \(\hat f_0\) と対照群の事後分布の更新に使う。

論文はこのペース配分を双対変数の乗法的な更新に「定性的に似ている」と位置づける。ただし双対上昇法として導いたものではなく、\(\lambda^{*}\) への収束やリグレットの保証もない、と明記している。予算を超えないことは、上の費用のチェックだけで保証される。

実験の設定

Criteo のランダム化実験のデータに架空の配信費用を加え、リプレイ法で評価した

データは Criteo Uplift データセット（v2.1）の 10% を抜き出した 1,397,959 件で、特徴量は 12 個、処置群と対照群の比は 85 対 15 である。購入率は処置群 0.31%、対照群 0.20% で、平均処置効果は 0.12% と小さい。データに配信費用は含まれないので、対数正規分布（\(\mu = -0.5,\ \sigma = 0.7\)）から費用を生成し、0.05〜5 ドルに切り詰めた。平均は 0.77 ドルで、結果とは独立に生成している。

評価はバンディットのリプレイ法による。利用者をランダムな順に流し、手法の判断が元の実験での割り当てと一致したときだけ実際の結果を観測して学習させ、一致しなければその利用者を飛ばす。オンライン手法の比較は 100,000 人の流れで予算 1,000〜8,000 ドル、オフライン手順との比較は同じ 100,000 人の流れに予算 5,000 ドルを固定し、オフライン手順に与える過去データを 500〜50,000 件で変える。BCCB には過去データを与えない。オフライン手順は過去データでロジスティック回帰のアップリフトモデルを学習し、費用対効果のしきい値で配る。主な結果は 20 シードの平均で、手法間の比較にはシードを対にした検定を使う。

主な評価指標は広告を出した人の購入数 \(\sum_t a_t Y_t(1)\) である。最適化の目的（増分の購入）とは対照群でも起きる購入の分だけ違うが、論文は、このデータでは差が小さく順位は変わらないと述べている。

以下の数値は arXiv v2（2026 年 8 月 28 日）の本文と表による。2026 年 11 月の時点で、出版版は確認できなかった。

実験の結果 1

5 つの予算すべてで、BCCB の転換数は 4 つのオンライン手法を上回った

比較相手は効果の個人差を考えずに処置群と対照群の購入率だけで判断する Thompson Sampling（TS）、それに予算とペース配分を加えた Budgeted TS、BCCB と同じ効果の推定を使うが探索もペース配分もせず推定値が正なら配る HTE Greedy、そして利用者ごとの効果を UCB 型の信頼上限で推定する Uplifting Bandits（UB）である。UB には BCCB と同じペース配分を加え、探索の方式（UCB とトンプソン抽出）だけが違うようにしている。

BCCB はすべての予算で平均転換数が最も多く、各手法との差はどれも p < 0.001 だった（Table 1）。UB との差は予算 1,000 ドルの +7.0 件から 8,000 ドルの +27.9 件に広がり、8,000 ドルでは 63.5 件対 35.7 件（+78%）である。TS と Budgeted TS はほぼ同じで、論文は効果の推定なしにペース配分だけ加えても得るものは少ないと読む。HTE Greedy は同じ推定器を使いながら最も弱く、探索しないため早い段階で悪い方策に落ち着くと論文は説明している。一方、BCCB のシード間の標準偏差（6.0〜13.7）は UB（1.5〜4.9）より大きい。

実験の結果 2

過去データが 7,500 件以上になると、オフライン手順の転換数が BCCB を有意に上回った

予算 5,000 ドルで、オフライン手順に与える過去データの件数 \(n\) を変えた（Table 2）。論文は「オフラインの平均が BCCB を上回り、片側の対応のある t 検定で p < 0.05 となり、それより大きい \(n\) でもずっと上回る最小の \(n\)」を交差点と定義し、それが \(n = 7{,}500\)（p = 0.043）だったと報告する。

  • \(n \le 1{,}000\)：オフライン手順は 4.7 件と 7.0 件で、BCCB の 49.4 件を大きく下回った。対照群に購入が 1 件もない学習データではモデルを当てはめられず、多くのシードで転換数が 0 になる。
  • \(2{,}000 \le n \le 5{,}000\)：平均は 39.0〜46.9 件で BCCB に近いが、標準偏差が 42.7〜58.7 と大きく、差は有意でない（p ≥ 0.6）。
  • \(n \ge 7{,}500\)：オフライン手順が上回り、差は \(n\) とともに広がる。50,000 件では 107.0 件で、BCCB の約 2.2 倍になった。

BCCB の標準偏差 16.2 はどの \(n\) でもオフライン手順の 2.3〜3.6 分の 1 である（Table 5）。論文はここから、代表的な過去データが約 7,500 件に満たないうちは BCCB を、それを超えたらオフライン手順を使う、という使い分けを提案している。なお、\(n = 7{,}500\) での差の 95% 信頼区間は \([-0.1,\ +45.7]\) と 0 をわずかに含む。

感度と注意点

大きく効くハイパーパラメータは探索の重み η と基準しきい値 λ で、評価の仕組みにも限界がある

予算 5,000 ドル、10 シードで 1 つずつ値を変えると、\(\eta\) を 0.001 から 0.1 に上げたとき転換数は 22.5 件から 43.9 件に増えた（Table 3）。\(\lambda\) は \(10^{-3}\) で最も高く、\(10^{-2}\) では 17.4 件に下がる。\(\varepsilon_{\mathrm{pace}}\) とウォームアップ \(W\) はほとんど効かなかった。\(\hat\tau_0\) は 0.001 のとき 51.4 件で、既定の 0.002（43.9 件）より高い。論文は \(\eta \in [0.05, 0.1]\)、\(\lambda \in [5\cdot10^{-4}, 10^{-3}]\) を推奨範囲としている。本文の要約は「5 つのうち 4 つに頑健で、注意して選ぶ必要があるのは \(\eta\) だけ」となっているが、Table 3 の変動係数は \(\lambda\)（0.36）のほうが \(\eta\)（0.32）より大きい。

評価の仕組みについて、論文は次の限界を挙げている。

  • 有効サンプル数：元の実験は処置群が 85% なので、リプレイで残る判断の数が手法によって違う。BCCB は 100,000 人のうち約 25%、TS は約 8% しか残らない（Table 4）。転換数はこの違いで補正していない。ただし、有効サンプル数が近い HTE Greedy と Budgeted TS の転換数は 13.30 件と 20.80 件で、BCCB の 45.65 件より少ない。
  • 架空の費用：費用は結果と独立に生成している。実際の入札価格が利用者の価値と相関すれば、1 ドルあたりの効果が変わりうる。
  • モデルと理論：効果の推定は線形のモデルで、リグレットの上界は示していない。実システムでの検証は今後の課題とされている。
予算制約つきアップリフトの中での位置づけ

金額の予算のもとで、1 ドルあたりの効果としきい値の比較をオンラインで行う

  • 推定するもの：二値の結果（購入）についての CATE \(\tau(\mathbf{x}) = P(Y{=}1 \mid \mathbf{x}, a{=}1) - P(Y{=}1 \mid \mathbf{x}, a{=}0)\)。2 つのロジスティック回帰をオンラインで学習する。
  • コストの扱い：利用者ごとの配信費用 \(c_t\) は判断の時点で分かり、特徴を条件として結果と独立だと仮定する。購入したときだけかかるコストのように、反応によって決まるコストは扱わない。実験の費用は対数正規分布で生成した架空の値である。
  • 処置：二値（広告を出すか出さないか）。
  • 予算制約：総費用 \(\sum_t a_t c_t \le B\)。理論（Proposition 1）は期待値の制約に緩めた問題を扱い、実際の判断では残り予算のチェックで本来の制約を守る。しきい値は残り予算と残り時間の比で動かす経験的なルールで、収束の保証はない。

判定ルール \(\tau(\mathbf{x}_t)/c_t > \lambda\) は、論文自身が予算つきの資源配分でよく知られた費用対効果のしきい値ルールだと述べている。ナップザック問題の連続緩和では、\(\tau/c\)（ROI）の大きい順に予算が尽きるまで配るのが最適で、これは最後に配る人の比をしきい値 \(\lambda\) にしたルールと同じになる。BCCB はこの ROI 順の割当てを、\(\tau\) も \(\lambda\) も分からない逐次の設定で近似するものと読める（解説者の注）。ただし ROI の分母は判断の時点で分かる配信費用で、処置後の反応で決まる期待コストではない。また、探索のゆらぎ \(b_t\) は同じ時刻の全員に共通で、個人の不確かさは反映しない。
