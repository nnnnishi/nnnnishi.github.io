Evaluating Treatment Prioritization Rules via Rank-Weighted Average Treatment Effects

順位で重み付けした平均処置効果（RATE）による、処置の優先順位ルールの評価

  • Steve YadlowskyGoogle DeepMind
  • Scott FlemingDepartment of Biomedical Data Science, Stanford University
  • Nigam ShahCenter for Biomedical Informatics Research, Stanford University
  • Emma BrunskillDepartment of Computer Science, Stanford University
  • Stefan WagerGraduate School of Business, Stanford University

誰から先に処置するかを決める優先順位ルールは、リスクスコア、CATE 推定、手作りの規則など、さまざまな方法で作られる。この論文は、順位の上位ほど処置効果が大きいかを表す TOC 曲線と、その重み付き面積 RATE を定義し、AUTOC と Qini 係数を一つの枠組みで推定・検定できるようにした。どちらの重みが検出力に有利かは効果の分布で変わることも示している。

背景

作り方の違う優先順位ルールを、処置効果の順位付けという一つの基準で比べたい

医療でもマーケティングでも、個人ごとに処置するかを決めるときは、まずスコアで人を並べ、費用や資源の制約を見ながら最終的な施策を決めることが多い。並べ方の一つは CATE（条件付き平均処置効果）を推定して効果の大きい順にすることだが、そのためには大きなランダム化実験か、それに相当する準実験が要る。もう一つは、処置しなかったときのリスク（ベースラインリスク）が高い順に並べる方法で、因果的な根拠はないが、学習に使えるデータがはるかに多い場合がある。

どちらのルールが「処置で得をする人」を上位に集められているのかを、作り方によらず同じ物差しで比べ、統計的に検定したい。論文はそのための指標として RATE（rank-weighted average treatment effect）を提案する。実装は R パッケージ grf の rank_average_treatment_effect 関数として公開されている。

定義

RATE は、上位 u の平均処置効果が全体平均をどれだけ上回るかを表す TOC 曲線の重み付き面積である

優先順位ルールは共変量 \(X\) からスコア \(S(X)\) を返す関数で、\(S\) の大きい人から処置する。\(F_S\) を \(S(X)\) の分布関数とすると、上位の割合 \(u\) について TOC（targeting operator characteristic）を次のように定義する。

\[ \mathrm{TOC}(u; S) = \mathbb{E}\bigl[\,Y(1)-Y(0) \mid F_S(S(X)) \ge 1-u\,\bigr] - \mathbb{E}\bigl[\,Y(1)-Y(0)\,\bigr] \]
\[ \theta_\alpha(S) = \int_0^1 \alpha(u)\,\mathrm{TOC}(u; S)\,du \]

重み関数 \(\alpha\) の選び方で既存の指標が現れる。\(\alpha(u)=1\) なら TOC の下の面積 AUTOC、\(\alpha(u)=u\) なら Qini 係数、\(\alpha\) を一点に集中させると「上位 u とそれ以外」の比較（high-vs-others）になる。RATE はスコアの値ではなく順位だけに依存するので、しきい値 \(s^*\) を使う AUPEC は RATE に含まれない。また、\(S(X)\) が処置効果と独立なら TOC も RATE も恒等的に 0 になる。

重みの意味

AUTOC は順位の先頭を強く重み付けし、Qini 係数は順位の前半と後半を対称に扱う

RATE は個人の処置効果を順位の分位で重み付けした平均としても書ける（論文の命題1）。AUTOC と Qini 係数の場合は次のとおりである。

\[ \mathrm{AUTOC}(S) = \mathbb{E}\Bigl[\bigl(-\log(1-F_S(S(X))) - 1\bigr)\bigl(Y(1)-Y(0)\bigr)\Bigr] \]
\[ \mathrm{QINI}(S) = \mathbb{E}\Bigl[\bigl(F_S(S(X)) - \tfrac12\bigr)\bigl(Y(1)-Y(0)\bigr)\Bigr] \]

図1のとおり、AUTOC の重みは優先度が最も高い人の近くで急に大きくなる。Qini 係数の重みは順位に対して直線的で、先頭と末尾を対称に扱う。この表現は推定量の作り方と漸近理論の出発点にもなる。

推定と推論

処置効果の代わりにスコアを重み付き平均した推定量は漸近正規で、半分サンプルのブートストラップで信頼区間が作れる

個人の処置効果は観測できないので、\(\mathbb{E}[\hat\Gamma_i \mid X_i] \approx \tau(X_i)\) を満たすスコア \(\hat\Gamma_i\) を代わりに使う。ランダム化実験なら IPW スコアで条件が厳密に成り立ち、AIPW スコアを使えば分散を下げられる。観測研究（無交絡を仮定）では AIPW スコア、打ち切りのある生存時間データでは補遺 A.3 の AIPW スコアを使う。局外パラメータはクロスフィッティングで推定する。評価用の \(n\) 人をルールの順に並べ、\(i(j)\) を \(j\) 番目の人とすると、推定量は次の形になる。

\[ \hat\theta = \frac{1}{n}\sum_{j=1}^{n} w_n\!\left(\frac{j}{n}\right)\hat\Gamma_{i(j)} \]

論文の中心極限定理は、重み・データ・局外パラメータについての仮定のもとで \(\hat\theta\) が漸近線形であり、したがって漸近正規であることを示す。重みが \(t \to 0\) で発散する AUTOC もこの仮定を満たす。分散を閉じた形で推定するのは面倒なので、\(\lfloor n/2 \rfloor\) 個を非復元抽出する半分サンプルのブートストラップで信頼区間と \(p\) 値を作る。通常のノンパラメトリック・ブートストラップも妥当だろうと著者らは予想しているが、証明はしていない。なお、ランダム化実験での Qini 曲線という最も単純な場合でも、中心極限定理とそれにもとづくガウス信頼区間はこの論文が初めてだと著者らは述べている。

ルール \(S\) は固定されたものとして扱い、評価用データはテストセットの役割だけを持つ。\(S\) を学習した場合、結果は学習した \(S\) を条件とした主張になる。「RATE が 0」という帰無仮説の検定は、\(S\) で予測できる形の処置効果の異質性がないかどうかの検定にもなる。

指標とスコアの選び方

効果のある人が少数に集中していれば AUTOC が、全体に広がっていれば Qini 係数のほうが検出力が高くなりやすい

論文のシミュレーションでは、\(X \sim \mathrm{Unif}(0,1)\)、\(\mu_0(x)=0\)、\(\mu_1(x)=\max(-2x/p^2 + 2/p,\,0)\) とし、CATE が 0 でない人の割合 \(p\) を 1.0、0.5、0.1 と変える。\(n=400\)、処置確率は 0.5、ノイズは \(\mathcal{N}(0, 0.2)\) で、ルール \(S(X)=1-X\) は効果の大きい順に並べる完全なルールである。オラクル AIPW スコアで AUTOC と Qini 係数を 10000 回計算して比べた（比較を公平にするため、Qini 係数の重みは AUTOC と同じ分散になるよう尺度をそろえている）。

効果が広く散らばる \(p=1.0\) では Qini 係数の検出力が高い傾向があり、効果が一部に集中する \(p=0.1\) では AUTOC の検出力が高かった。この傾向は IPW スコアや推定した AIPW スコアでも変わらない（補遺）。スコアについては、同じ設定で AIPW スコアのほうが IPW スコアより推定値の分散が小さく、検出力が高かった。論文はランダム化実験でも観測研究でも AIPW スコアを勧めている。迷ったときは AUTOC から始めることも勧めている。

応用

実データでは、リスク層別では有意にならなかった効果の差を RATE が検出し、Criteo では AUTOC だけがルール間の差を捉えた

アスピリンと脳卒中（IST）。36か国 19,435 人のランダム化試験で、6か月後の死亡または要介護を結果とし、半分で学習、残り半分で評価した。リスクの高い人ほど効果が小さいという仮説に沿って、リスクの高い人を先に並べた。ランダムフォレストのリスクスコアによる AUTOC は 0.014（95%CI 0.002–0.027、\(p\) = 0.022）で、論文はこれを主解析とし、多重比較の補正はしていない。ロジスティック回帰のリスクスコアは 0.011（\(p\) = 0.057）、因果フォレストは 0.006（\(p\) = 0.493）、ロジスティック回帰の T-learner は 0.005（\(p\) = 0.588）だった。先行研究ではリスクで3群に分けた解析で有意にならなかった。論文はこの結果を、リスクの分位ごとに効果を推定するより RATE のほうが検出力が高いことの表れとしている。

降圧治療（SPRINT と ACCORD-BP）。一方の試験で学習したルールを他方で評価したところ、リスクスコアにもとづくルールも CATE にもとづくルールも、RATE は 0 と有意に違わなかった。論文は、これらの試験で異質性を主張するのは脆いと述べている。

広告のアップリフト（Criteo）。25,309,483 件のデータから、処置群・対照群 16 万件ずつの 32 万件を学習用と評価用に一組ずつ取り出した。処置しないときの訪問・購入確率を予測するベースラインルールと、因果フォレストによる CATE ルールを比べると、どちらも 0 より有意に大きかった（図2）。訪問では AUTOC の差が 0.0034（95%CI 0.0019–0.0049、相対的に 25% 増）で有意だったが、Qini 係数の差と購入での差は有意でなかった。論文の説明では、CATE ルールの優位は処置する割合が小さいところに集中し、処置割合が 10% を超えると差が消える。Qini 係数はこの小さな上位群を軽く扱うので差が出にくい。

位置づけ

RATE は処置する人の割合を横軸に順位の良さを測る指標で、費用を横軸にした評価は論文の範囲外である

この文献リストが扱うのは、予算の中で増分の売上や利益を最大化する設定である。たとえば解説者も共著の松井ら（2023、日本OR学会春季研究発表会）は、購買したときだけ一定額 \(C\) の費用がかかる固定額インセンティブを考え、緩和したナップサック問題の貪欲解として \(\rho = \mathbb{E}[V(1)-V(0)] \,/\, (C\,\mathbb{E}[Y(1)])\) の大きい順に配る（\(V\) は売上、\(Y\) は購買の有無。論文のスコア \(S\) と区別するため売上を \(V\) と書く）。

RATE はスコアの作り方を問わないので、\(\rho\) の推定値もそのまま \(S\) として評価できる。ただし RATE が測るのは、上位 \(u\) の平均処置効果が全体平均をどれだけ上回るかであり、横軸は処置する人の割合である。1人あたりの費用が人によって違う設定（ここでは \(C\,\mathbb{E}[Y(1)]\)）では、同じ \(u\) でも使う予算がルールごとに違う。そのため、TOC で上位になったルールが、同じ予算での増分売上でも上位になるとは限らない。

横軸を累積費用に替えると、次の点が変わる。第一に、購買時にだけ費用がかかるなら費用は結果に依存するので、横軸そのものを推定する必要がある。第二に、論文の RATE と定理は、重みが順位の分位 \(F_S(S(X))\) だけで決まる形を前提にしている。累積費用で重み付けする指標はこの定義の外にあり、論文の中心極限定理がそのまま使えるかは示されていない。論文は関連研究として、費用が未知で人により異なる場合の指標を扱った研究に触れているが、本文では扱っていない。

一方で、論文の考察が述べるように、RATE は施策（しきい値や予算）が決まる前に順位の質を測るための道具である。しきい値が決まっているなら high-vs-others で評価するのが妥当だと論文は述べている。ただし購買時にだけ費用がかかる設定では、予算に対応する \(u\) をルールごとに推定する必要があり、その手続きは論文にはない。
