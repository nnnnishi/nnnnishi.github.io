Bi-Level Decision-Focused Causal Learning for Large-Scale Marketing Optimization: Bridging Observational and Experimental Data

大規模マーケティング最適化のための二段階の決定重視因果学習：観察データと実験データの橋渡し

  • Shuli Zhang1
  • Hao Zhou1,2
  • Jiaqi Zheng1
  • Guibin Jiang2
  • Bing Cheng2
  • Wei Lin2
  • Guihai Chen1

1State Key Laboratory for Novel Software Technology, Nanjing University, Nanjing, China
2Meituan, Beijing, China

クーポンや割引の配分を学習するとき、観察データは大量にあるが偏っており、RCT データは偏りがないが少ない。Bi-DFCL は RCT データで推定した「予算内での配分の質」を使って、観察データでの学習の向きを補正する。これにより、両方のデータを一つのモデルの学習に使える。

背景

予測してから最適化する二段階法には、予測と決定のずれ、偏りと分散のジレンマという二つの課題がある

論文が扱うのは、\(N\) 人（または店舗）それぞれに \(M\) 種類の施策のどれか一つを割り当てる問題である。個人 \(i\) に施策 \(j\) を割り当てたときの売上を \(r_{ij}\)、コストを \(c_{ij}\) とし、総コストを予算 \(B\) 以内に抑えながら総売上を最大にする。論文はこれを MTBAP（Multi-Treatment Budget Allocation Problem）と呼ぶ。

\[ \max_{z}\ \sum_{i}\sum_{j} z_{ij}\, r_{ij} \quad \text{s.t.}\ \ \sum_{i}\sum_{j} z_{ij}\, c_{ij} \le B,\ \ \sum_{j} z_{ij} = 1,\ \ z_{ij}\in\{0,1\} \]

これは NP 困難な多選択ナップサック問題（MCKP）であり、ラグランジュ緩和で近似的に解く。二分探索で乗数 \(\lambda^*\) を決め、各人に \(\hat r_{ij} - \lambda^* \hat c_{ij}\) が最大の施策を割り当てる。

\[ z^*_{ij} = \mathbb{1}\Bigl\{\, j = \arg\max_{j'} \bigl[\hat r_{ij'} - \lambda^* \hat c_{ij'}\bigr] \Bigr\} \]

従来の二段階法はまず機械学習で \(\hat r, \hat c\) を予測し、次にこの最適化で配分を決める。論文はここに二つの課題を挙げる。一つは予測の精度が上がっても配分の質が上がるとは限らないこと（予測と決定のずれ）であり、もう一つは、観察データは多いが偏り（高バイアス・低分散）、RCT データは偏りがないが少ない（低バイアス・高分散）ことである。

問題

既存の決定重視学習は決定損失を偏りのない RCT データでしか計算できず、豊富な観察データを捨てている

予測と決定のずれに対処する方法として、配分の質そのものを損失にして学習する決定重視学習（DFL）がある。マーケティング向けには DHCL と DFCL が提案されている。ただし、反実仮想（実際には割り当てなかった施策での結果）は観測できないため、決定損失を偏りなく推定できるのは RCT データだけである。その結果、これらの手法は少ない RCT データでしか学習できず、過学習しやすい（低バイアスだが高分散）。

論文は DFCL の不足をさらに二つ指摘する。一つは予測損失と決定損失の重み \(\alpha\) を手で調整する必要があることであり、もう一つは、DFCL の双対の決定損失があらゆる予算での配分の質を評価するのに対し、実際の予算は狭い範囲か、いくつかの候補値に限られることである。

手法 1：決定損失

RCT データなら、予算 B のもとでの配分の質を不偏に推定でき、微分できる代理損失に置き換えられる

RCT では施策が無作為に割り当てられるので、実際に受けた施策 \(t_i\) の結果だけを使い、各施策の人数 \(N_{t_i}\) で重み付けすれば、決定損失（配分の売上の符号を反転したもの）を不偏に推定できる（論文 Appendix A.2 に証明がある）。

\[ \mathcal{L}_{\mathrm{DL}}(\theta; \mathcal{D}_{\mathrm{RCT}}) = -\,\mathbb{E}_{i}\Bigl[\, \frac{N}{N_{t_i}}\; z^*_{it_i}\bigl(\hat r(\theta), \hat c(\theta)\bigr)\; r_{it_i} \Bigr] \]

ただし \(z^*\) は argmax の指示関数なので、そのままでは \(\theta\) で微分できない。論文は二つの代理損失を用意する。PPL（primal policy learning）は、指示関数を softmax で緩めた方策の期待売上を最大にする。

\[ \mathcal{L}_{\mathrm{PPL}} = -\,\mathbb{E}_{i}\Biggl[\, \frac{N}{N_{t_i}} \cdot \frac{\exp[\hat r_{it_i} - \lambda^* \hat c_{it_i}]}{\sum_{j} \exp[\hat r_{ij} - \lambda^* \hat c_{ij}]} \cdot r_{it_i} \Biggr] \]

PIFD（primal improved finite difference）は、決定損失を少しずらしたときの変化から勾配を直接見積もる。緩和をしないので、元の最適化の形を保てる。どちらも二分探索で求めた実際の予算 \(B\) に対応する \(\lambda^*\) を使う。この点がすべての予算を評価する DFCL の双対の損失との違いである。

手法 2：二段階最適化

下位問題で観察データの予測損失を、上位問題で RCT データの決定損失を最小化し、ブリッジネットワークが両者をつなぐ

論文によれば、決定損失を偏った観察データで最小化すると、偏りが大きく増幅される。一方、予測損失は汎化を良くするためのもので、大量で分散の小さい観察データで使うと効果が大きい。そこで論文は二つの損失を役割で分け、入れ子の二段階最適化にする。

\[ \phi^* = \arg\min_{\phi}\ \mathcal{L}_{\mathrm{DL}}\bigl(\theta^*(\phi); \mathcal{D}_{\mathrm{RCT}}\bigr) \quad \text{s.t.}\quad \theta^*(\phi) = \arg\min_{\theta}\ \mathcal{L}_{\mathrm{PL}}(\phi, \theta; \mathcal{D}_{\mathrm{OBS}}) \]

\(\theta\) は最終的に使うターゲットネットワーク、\(\phi\) はブリッジネットワークのパラメータである。ブリッジネットワークは個人と施策の組ごとに重み \(w \in (0,1)\) を出し、観察データで観測されていない施策について疑似ラベルを作る。疑似ラベルは RCT データで事前学習して固定した教師ネットワーク \(\psi\) の予測と、ターゲットネットワークの予測を \(w\) で混ぜたものである（コスト \(c\) についても同じ）。

\[ r^{\mathrm{cf}}_{ij} = \hat r^{\mathrm{pre}}_{ij}(\psi)\, w^{r}_{ij} + \hat r_{ij}(\theta)\,\bigl(1 - w^{r}_{ij}\bigr), \qquad w^{r}_{ij} = \operatorname{sigmoid}\bigl(\mathcal{G}^{r}_{\phi}(i,j)\bigr) \]

下位問題の予測損失は、観測された施策では実際の結果との二乗誤差、それ以外の施策では疑似ラベルとの二乗誤差である。上位問題はこうして学習したターゲットネットワークの配分の質を RCT データで測り、それが良くなるように \(w\) の出し方を変える。予測損失と決定損失の釣り合いもデータから決まるので、DFCL の \(\alpha\) を手で調整する必要がなくなる。

手法 3：学習アルゴリズム

上位問題の勾配は下位問題の最適性条件を微分する陰関数微分と共役勾配法で、ヘッセ行列の逆行列を作らずに求める

ブリッジネットワークを更新するには、\(\phi\) を変えたときに下位問題の解 \(\theta^*(\phi)\) がどう動くか（ヤコビ行列）が必要である。勾配降下の1ステップを通して微分する方法（陽な微分）もあるが、論文によれば、最適化の経路に依存し、決定損失と組み合わせると勾配が消えやすい。そこで、\(\theta^*(\phi)\) が満たす一階条件を \(\phi\) で微分する。

\[ \frac{\partial^2 \mathcal{L}_{\mathrm{PL}}}{\partial \theta^2}\Big|_{\theta^*(\phi)} \cdot \frac{\partial \theta^*(\phi)}{\partial \phi} = -\,\frac{\partial^2 \mathcal{L}_{\mathrm{PL}}}{\partial \phi\, \partial \theta}\Big|_{\theta^*(\phi)} \]

この線形方程式を、ヘッセ行列とベクトルの積だけを使う共役勾配法で解く。実装では \(k\) バッチに1回（既定値 \(k=5\)）上位問題を解き、そのときは \(k\) ステップの仮の更新で \(\theta^*(\phi)\) を近似する。共役勾配法の反復回数の既定値は 50 である。

代わりに学習時間は増える。Marketing Data II での学習時間は、Bi-DFCL-PPL が 265.263 分、Bi-DFCL-PIFD が 294.927 分で、両方のデータで学習した TSM-SL の約 6〜7 倍だった（論文 Table 8）。陰関数微分を使わないと学習時間はさらに長く、それぞれ 345.132 分と 427.515 分だった。推論ではターゲットネットワークだけを使うので、推論時間は単純な因果モデルと変わらない。

実験

公開データ、美団の2種類のデータ、4週間のオンライン A/B テストのすべてで、Bi-DFCL は比較手法を上回った

オフライン実験には3つのデータセットを使う。CRITEO-UPLIFT v2 は RCT データの一部を、模擬した施策方針で観察データに作り替えたもので、処置は2値である。Marketing Data I は美団の値引き施策（8段階）、Marketing Data II は割引施策（5段階）で、それぞれ RCT データと観察データを含む。比較手法は RCT データだけ、観察データだけ、両方で学習する3群に分かれる。評価指標は2値の処置では AUCC、多値の処置では EOM（RCT データから配分の期待売上を不偏に推定する指標）である。

Bi-DFCL は3つのデータセットすべてで最良だった。要素を一つずつ加えるアブレーション（論文 Table 3）では、Marketing Data I の改善率が、決定損失（PPL）で 1.67%、二段階最適化を加えて 2.40%、疑似ラベルを加えて 2.48%、陰関数微分を加えて 2.77% と段階的に上がった。Marketing Data I の観察データ 22,201,405 件に組み合わせる RCT データを 222,000 件、1,100,000 件、2,220,781 件と増やすと、改善率は 1.90%、2.58%、2.77% だった（論文 Table 6）。

オンラインでは、美団の割引施策（割引率 0・5・10・15・20%）で、日ごとにわずかに変わる予算のもとで注文数を最大にする設定の A/B テストを4週間行った。79万店舗を毎日5群に無作為に分けて比較した結果、TSM-SL に対する改善率は LTD-DR が 0.91%、DFCL-PIFD が 1.80%、Bi-DFCL-PPL が 3.00%、Bi-DFCL-PIFD が 3.22% だった（論文 Table 4）。論文によれば、Bi-DFCL は美団の複数のマーケティング施策ですでに運用されている。

予算制約つきアップリフトの中での位置づけ

Bi-DFCL は処置ごとの売上とコストを予測するモデルを、予算内の配分の質が上がるように RCT と観察データの両方で学習する

  • 何を推定するか：アップリフト（差）そのものではなく、個人 \(i\) と施策 \(j\) の組ごとの売上 \(\hat r_{ij}\) とコスト \(\hat c_{ij}\) を予測する。配分は \(\hat r_{ij} - \lambda^* \hat c_{ij}\) が最大の施策を選んで決める。
  • コストの扱い：コスト \(c_{ij}\) も売上と同じく観測される結果として扱い、データから予測する。美団のデータでは日ごとのコスト、CRITEO では visit をコストとみなしている。費用の発生の仕組み（たとえば購入したときだけかかる）を式に組み込むことはしていない。
  • 予算制約：予算 \(B\) は1つの合計コストの制約であり、RCT データでの1人あたりの推定コストが \(B/N\) に合うように \(\lambda^*\) を二分探索で決める。決定損失はこの \(B\) での配分の質を対象にする。付録では、10通りの予算でも Bi-DFCL の EOM が高いことを示している（論文 Fig. 3）。
  • 処置の数：多値の処置（各人にどれか一つ）を前提とし、実験では2値（CRITEO）、5値、8値を扱う。
  • 必要なデータ：RCT データと観察データの両方を使う。教師ネットワークの事前学習と上位問題の決定損失は RCT データに頼るので、RCT データが全くない状況は想定していない。

解説者の補足として、2値の処置で施策を受けたときの増分コストが正なら、\(r_{i1} - \lambda c_{i1} > r_{i0} - \lambda c_{i0}\) は「増分コストあたりの増分売上が \(\lambda\) を超える人に配る」ことと同じである。この点で、増分売上を期待コストで割った比で順位づける方法（たとえば西村らの 2023 年の研究の \(\rho = \mathbb{E}[S(1) - S(0)] / (C \cdot \mathbb{E}[Y(1)])\)）と同じ形の配分規則になる。ただし、論文はこうした手法とは比較していない。

まとめ

観察データの量と RCT データの偏りのなさを、配分の質を基準に組み合わせる方法である

Bi-DFCL は RCT データで不偏に推定した決定損失を上位問題に、観察データでの予測損失を下位問題に置き、ブリッジネットワークの疑似ラベルで両者をつなぐ。論文はオフライン実験とオンライン A/B テストのどちらでも既存手法を上回ったと報告している。一方で、学習時間は単純な二段階法の数倍かかる。論文は今後の課題として、計算効率の改善と、他の意思決定の分野への応用を挙げている。
