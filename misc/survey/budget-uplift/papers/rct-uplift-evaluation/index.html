European Journal of Operational Research · 2024

Improving uplift model evaluation on randomized controlled trial data

ランダム化比較試験データでのアップリフトモデル評価の改善

  • Björn BokelmannChair of Information Systems, Humboldt University Berlin
  • Stefan LessmannChair of Information Systems, Humboldt University Berlin

アップリフトモデルを RCT データで評価するとき、Qini 曲線や変換アウトカムの平均二乗誤差 \(MSE_W\) の値は、テストデータの偶然で大きくばらつく。この論文はばらつきの原因を式で分解し、学習データで作った予測をテストデータの元のアウトカムから引いた調整後のアウトカムで指標を計算すれば、偏りを入れずに分散を減らせることを示す。シミュレーションと 3 つの実データのどの設定でも、分散は減った。

背景

アップリフトモデルの評価では、観測できない CATE の代わりに処置群と対照群の差を使う

予測モデルなら、テストデータの正解と予測を比べれば評価できる。ところがアップリフトモデルが当てたい CATE（条件付き平均処置効果）は、一人ひとりについては観測できない。観測できるのは、処置を受けた場合と受けなかった場合のどちらか一方の結果だけである。そのため評価では処置群と対照群の結果の差を CATE の代わりに使う。

論文は評価指標を 3 種類に分ける。モデルが上位に並べた割合 \(s\) の人について処置群と対照群の平均の差を取る順位の指標（Qini 曲線、アップリフト曲線）、CATE の予測値の正確さを測る精度の指標（変換アウトカムの平均二乗誤差 \(MSE_W\)）、モデルから決めた処置の割当てを評価する決定の指標である。本文は前の 2 つを分析し、結果が決定の指標にも当てはまることを付録で示している。精度の指標は順位の指標ほど使われていない。それでも、処置のコストが人によって違うときは順位だけでは処置を決められないので、精度の指標も重要だと論文は述べる。

RCT では処置がランダムに割り当てられるので、これらの指標に偏りはない。問題は分散である。テストデータは有限なので、同じモデルでもテストデータが変われば評価も変わる。論文は、従来の計算方法は分散の点で最適ではなく、多くの研究がデータを十分に生かせていないと指摘する。

理論

評価指標のばらつきは、変換アウトカムが CATE の周りでどれだけ揺れるかで決まる

処置確率 \(p\) が全員共通の RCT を考え、アウトカムを次のように書く。\(W\in\{0,1\}\) は処置の有無、\(\mu_x\) は対照群での条件付き期待値、\(\tau_x\) は CATE、\(\varepsilon\) は特徴量では説明できないノイズである。

\[ Y = \mu_x + W\,\tau_x + \varepsilon \]

\(MSE_W\) は観測できない \(\tau_x\) を変換アウトカム \(W^pY\) で置き換えた平均二乗誤差である。ここで \(W^p = W/p - (1-W)/(1-p)\)（Horvitz–Thompson 変換）で、\(W^pY\) の期待値は \(\tau_x\) になる。Qini 曲線の各点（上位 \(s\) の人での処置群と対照群の平均の差）も、上位 \(s\) に含まれる処置群の割合 \(\tilde p\) を使うと同じ形に書ける。どちらの指標も、減らせる分散は \(W^pY\) の分散で決まる。\(W^pY\) は次のように分解できる。

\[ W^pY = \tau_x + \underbrace{W^p\,\Phi(X)}_{\color{#C2410C}{\text{減らせる揺れ}}} + W^p\varepsilon, \qquad \Phi(X) := \mu_x + (1-p)\,\tau_x \]

右辺の \(\tau_x\) 以外の項は、\(W^pY\) を \(\tau_x\) の周りで揺らすだけである。\(W^p\varepsilon\) は説明できないノイズによるので減らせないが、論文が局外関数（nuisance function）と呼ぶ \(\Phi(X)\) による揺れは減らせる。分散を 2 つの成分に分けると、次のようになる。

\[ \mathbb{E}\big[\mathrm{Var}[W^pY\mid W]\big] = \mathrm{Var}[\tau_x] + \frac{\mathrm{Var}[\Phi(X)] + \mathrm{Var}[\varepsilon]}{p(1-p)}, \qquad \mathrm{Var}\big[\mathbb{E}[W^pY\mid W]\big] = \frac{\mathbb{E}[\Phi(X)]^2}{p(1-p)} \]

\(MSE_W\) の分散には両方の成分が効き、Qini 曲線には 1 つ目の成分だけが効く（\(p\) を \(\tilde p\) に置き換える）。つまり \(\Phi(X)\) の分散と平均を小さくできれば、指標の分散が減る。

手法

学習データで当てた予測をテストデータのアウトカムから引くと、偏りを入れずに分散を減らせる

手順は単純である。学習データで \(\Phi(X)\) を近似する関数 \(\hat\Phi(X)\) を作り、テストデータでは \(Y\) の代わりに調整後のアウトカム \(Y-\hat\Phi(X)\) で指標を計算する。すると減らせる揺れは \(W^p(\Phi(X)-\hat\Phi(X))\) に縮む。分散が減る条件は次の 2 つである。

  • (C1) \(\;|\mathbb{E}[\Phi(X)]-\mathbb{E}[\hat\Phi(X)]| < |\mathbb{E}[\Phi(X)]|\)：満たせば \(MSE_W\) の分散が減る。
  • (C2) \(\;\mathrm{Var}[\Phi(X)-\hat\Phi(X)] < \mathrm{Var}[\Phi(X)]\)：満たせば \(MSE_W\) の分散がさらに減り、Qini 曲線の分散も減る。

論文はこの条件から 3 つの調整方法を導く。

  • 無条件平均調整（AM1）：\(\hat\Phi = (1-p)\hat\mu_1 + p\,\hat\mu_0\)。学習データの処置群と対照群の平均から作る定数なので C2 には効かず、Qini 曲線の分散は変わらない。
  • 二重頑健調整（AM2）：\(\hat\Phi = (1-p)\hat\mu_1(x) + p\,\hat\mu_0(x)\)。処置群と対照群のそれぞれで学習した予測モデルを使う。\(W^p(Y-\hat\Phi)\) は、よく知られた二重頑健なアウトカム変換で傾向スコアを定数 \(p\) にしたものと一致する。
  • 条件付き平均調整（AM3）：\(p = 0.5\) のときは \(\Phi(X) = \mathbb{E}[Y\mid X]\) なので、処置群と対照群をまとめて学習した予測 \(\hat\mu(x)\) を使う。

\(\hat\Phi\) はテストデータの上では固定された関数なので、引いても \(\mu_x\) がずれるだけで指標の期待値は変わらない。ただしこれは \(\hat\Phi\) をテストデータで学習しない場合に限る。また論文は、\(\hat\Phi\) が定数による予測 \(\mathbb{E}[\Phi(X)]\) より正確なら C2 が成り立ち、\(\mathbb{E}[\Phi(X)]\) がほぼ 0 でない限り C1 もまず成り立つと論じている。

信頼区間の幅は指標の分散の平方根に比例し、テストデータの件数の平方根に反比例する。このため、分散を x% 減らせば、同じ幅の信頼区間を得るのに必要なテストデータも x% 減らせる。

実験の設定

2 種類のシミュレーションと 3 つの実 RCT データで、元のアウトカムと調整後のアウトカムの分散を比べた

シミュレーションには grf パッケージの generate_causal_data を使い、Wager & Athey（2018）と Nie & Wager（2021）の設定（論文の記号で "aw" と "nw"）を選んだ。処置確率は 0.5、特徴量は 6 個、ノイズの標準偏差 \(\sigma\) は 0.5、1、2 の 3 通りである。各設定で 15,000 件のデータを 10,000 回作り、10,000 件で学習、5,000 件で評価した。

実データは Criteo（13,979,592 件、処置確率 0.85）、Hillstrom（男性向け広告の群を除いた 42,693 件、処置確率 0.5）、オンライン小売のクーポン配布データ（144,630 件、処置確率 0.75。論文の記号で "private"）の 3 つである。Hillstrom と private は 80% を学習に、20% をテストに使い、Criteo は 90% をテストに使った。評価するモデルは因果フォレスト（grf）で、調整用の \(\hat\mu,\,\hat\mu_0,\,\hat\mu_1\) はランダムフォレスト（ranger）で作った。

\(MSE_W\) については因果フォレストと常に 0 を予測するモデルとの差 \(\Delta MSE_W\) の分散を比べた。調整すると \(MSE_W\) そのものの期待値は変わるが、差の期待値は変わらないからである。Qini 曲線はシミュレーションでは \(s = 0.1\) の点、実データでは 10% 刻みの各点で比べた。実データではデータを繰り返し作れないので、信頼区間の計算に使う分散の推定値で比べている。

以下の数値は arXiv v3（2022 年 12 月 16 日、題名は "Improving uplift model evaluation on RCT data"）の本文と表による。EJOR 掲載版の本文は取得できなかったため、照合していない。なお arXiv v3 では、4.3 節が信頼区間の幅を「テストデータの件数に反比例する」と書いている一方、付録 C の式は件数の平方根に反比例する形になっている。また付録 C の Qini 曲線の信頼区間の式は、直前に示した分散 \(\sigma_s^2\) の式と分母の書き方が異なっている。

実験の結果 1

調整はどの設定でも分散を減らし、実データでは \(\Delta MSE_W\) の分散が 12.4〜34.1% 減った

シミュレーション（Table 1）では、\(\Delta MSE_W\) の分散が無条件平均調整で 28.4〜89.7%、条件付き平均調整と二重頑健調整で 44.4〜97.8% 減った。\(\Delta MSE_W\) では、ノイズの \(\sigma\) が大きいほど減り方が小さい。Qini 曲線（\(s = 0.1\)）の分散は、条件付き平均調整と二重頑健調整で 10.1〜71.9% 減った。

実データ（Table 2）でも、すべての指標で分散が減った。\(\Delta MSE_W\) では、条件付き平均調整と二重頑健調整の減少率が 12.4〜34.1% で、無条件平均調整（0.4〜16.4%）をどのデータでも上回った。Qini 曲線では private で 15.1〜25.1%、Criteo で 11.3〜13.7% 減ったが、Hillstrom では 1.75〜3.30% にとどまった。論文によると、Hillstrom は処置効果の異質性が大きい一方で \(\mu_x\) の異質性が小さく、減らせる分散がもともと少ない。

シミュレーションより実データで減り方が小さいのは、実データのほうがノイズの影響が大きいからだろうと論文は推測している。

実験の結果 2

調整すると、モデルの優劣を取り違える評価が減った

Table 3 は、シミュレーションで \(\Delta MSE_W\) がモデルの優劣を逆に判定した割合である。因果フォレストの比較相手は真の CATE（完全な予測）、常に 0 を予測するモデル、因果フォレストの予測にノイズを加えた劣化版の 3 つである。

aw（\(\sigma = 0.5\)）では、元のアウトカムの \(MSE_W\) は 39.3% の回で、因果フォレストのほうが完全な予測より良いと判定した。調整後は、条件付き平均調整で 4.5%、二重頑健調整で 4.4% に下がった。すべての設定と比較相手で、どの調整方法も誤判定の割合を下げた。条件付き平均調整と二重頑健調整の割合は、どの行でも無条件平均調整と同じか、それより低い。劣化版との比較では元のアウトカムで 45.6〜48.6%、調整後も 38.8〜46.4% が誤判定だった。

これらの結果から論文は、元のアウトカムで計算した \(MSE_W\) は使わないよう勧めている。調整方法では、学習が要らない無条件平均調整がいちばん手軽だが、条件付き平均調整や二重頑健調整には劣るとしている。

予算制約つきアップリフトの中での位置づけ

予算も処置コストも扱わず、RCT での評価指標の分散を減らす方法を示す

  • 何を推定するか：新しいアップリフトモデルは提案しない。学習済みモデルの CATE 予測や順位を、RCT のテストデータでどう評価するかを扱う。学習データで当てるのは、評価のための補助の予測 \(\hat\Phi(X)\)（アウトカムの条件付き期待値）である。
  • コストの扱い：処置コストは式に出てこない。付録では、処置を決めるごとにコスト \(c\) を足す targeting profit（Hitsch & Misra）にも同じ分析が当てはまり、コストは統計的な性質に関係しないと述べている。序論では、コストが人によって違うときは順位だけでは処置を決められないことを、精度の指標 \(MSE_W\) を扱う理由に挙げている。
  • 処置の種類：二値で、処置確率 \(p\) は全員共通の定数（RCT）。傾向スコアが人によって違う観測データは対象外である。2 種類の広告がある Hillstrom は、片方の群を除いて二値にしている。
  • 予算制約の扱い：予算は Qini 曲線の横軸である処置する人の割合 \(s\) として現れるだけで、金額の予算や総コストの上限は扱っていない。

ROI 順の割当てとの関係は次のように整理できる（解説者の注）。予算のもとでナップザック問題の連続緩和を解くと、「増分の利益 ÷ 期待コスト」の大きい順に配ることになる。こうした方策どうしを同じ予算で比べるのは、論文の分類では決定の指標の差 \(\hat v(d_1)-\hat v(d_2)\) に当たる。付録は、この差が変換アウトカムの和で書けるので調整で分散が減ること、また差を取れば調整による偏りが消えることを示している。そのため、ROI 順の方策を予算ごとに比べる場面にもこの調整は使えると考えられる。ただし購入したときだけコストがかかる場合は、予算に対応する人数がアウトカムによって変わる。横軸を累積コストにした曲線の分散は、この論文では分析されていない。
