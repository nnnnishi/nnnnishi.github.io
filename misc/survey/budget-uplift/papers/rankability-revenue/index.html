Rankability-enhanced Revenue Uplift Modeling Framework for Online Marketing

オンラインマーケティングのための、順位づけ性能を高めた売上アップリフトモデリング

  • Bowei HeCity University of Hong Kong（FiT, Tencent でのインターン中の研究）
  • Yunpeng WengFiT, Tencent

売上のアップリフトを推定するとき、反応は 0 が大半を占め、ごく一部が非常に大きい値をとる。従来のモデルは一人ひとりの売上を MSE で回帰するが、施策で実際に使うのはアップリフトの順位である。この論文は売上を ZILN 損失で回帰したうえで、2 種類の順位損失を加えて順位を直接学習する枠組み RERUM を提案し、公開データ、Tencent の自社データ、オンライン実験で評価している。

背景

売上のアップリフトは 0 が多く裾の長い連続値を相手にし、順位の正しさが問われる

マーケティングのアップリフトモデリングは、購入したかどうか（0/1）を扱うコンバージョンのアップリフトと、支払った金額を扱う売上のアップリフトに分かれる。論文は企業の収入に直結する後者に取り組む。推定する量は共変量 \(\mathbf{x}\) のもとでの処置群と対照群の期待売上の差（CATE）である。

\[ \tau(\mathbf{x}) = \mathbb{E}[Y \mid X=\mathbf{x},\, T=1] - \mathbb{E}[Y \mid X=\mathbf{x},\, T=0] \]

論文は売上を扱う難しさを 2 つ挙げる。1 つは分布の形で、論文の配信基盤での A/B テストでは売上の大部分が 0 か小さな値で、0 を除いて対数をとるとおおむね正規分布になる。投資信託の販売額は 0 や数ドルから数百万ドル以上にまで及びうる。MSE 損失はこのような外れ値の影響を受けやすい。もう 1 つは目的のずれで、既存手法の多くはアップリフトの値の正確さだけを見ている。しかし施策では効果の大きい人から順に介入する。論文は、値が多少ずれても真の順位が保たれることのほうが実務では重要だと述べる。

手法 1

ZILN 損失は売上を「買うか」と「買った人の金額」に分け、金額は対数正規分布で回帰する

顧客生涯価値の研究にならい、論文は MSE の代わりに zero-inflated lognormal（ZILN）損失を使う。第 1 項は売上が正かどうかを確率 \(p\) で当てる交差エントロピー、第 2 項は支払った人だけについて、売上を平均 \(\mu\)、標準偏差 \(\sigma\) の対数正規分布とみなした負の対数尤度である。0 の人は金額の回帰に入らず、対数をとるので大きな値の影響も弱まる。

\[ \mathcal{L}_{\mathrm{ZILN}} = \underbrace{-\mathbb{1}(y{=}0)\log(1-p) - \mathbb{1}(y{>}0)\log p}_{\text{買うか}} \;+\; \underbrace{\mathbb{1}(y{>}0)\Big[\log\!\big(y\sigma\sqrt{2\pi}\big) + \frac{(\log y-\mu)^2}{2\sigma^2}\Big]}_{\text{買った人の金額}} \]

この損失に合わせて、既存のアップリフトモデルの出力部分を作り替える。共通の表現学習部の上に処置群用と対照群用の出力部を置き、それぞれが \((p^1,\mu^1,\sigma^1)\) と \((p^0,\mu^0,\sigma^0)\) を出す。CFR の分布を揃える項や DragonNet の傾向スコアの出力部は、元のモデルにあれば残す。論文は、この枠組みが特定のモデルに依存しないと述べている。

理論

2 人のアップリフトの差の誤差は個人ごとの回帰誤差よりきつい 2 つの上界で抑えられる

順位を正しくするには、任意の 2 人 \(i, j\) について予測の差 \(\hat\tau_i - \hat\tau_j\) が真の差 \(\tau_i - \tau_j\) に近ければよい。論文は \(\hat\tau = \hat y^1 - \hat y^0\) を代入して三角不等式を 2 段階で使い、この誤差を次のように抑える。

\[ \begin{aligned} \big|(\hat\tau_i-\hat\tau_j)-(\tau_i-\tau_j)\big| &\le \textcolor{#1D4ED8}{\big|(\hat y^1_i-\hat y^1_j)-(y^1_i-y^1_j)\big| + \big|(\hat y^0_i-\hat y^0_j)-(y^0_i-y^0_j)\big|} \\ &\le \textcolor{#C2410C}{|\hat y^1_i-y^1_i| + |\hat y^1_j-y^1_j| + |\hat y^0_i-y^0_i| + |\hat y^0_j-y^0_j|} \end{aligned} \]

中段は、同じ群の中での 2 人の応答の差がどれだけずれているかを表す。項の組み方を変えると、もう 1 つの中間の上界 \(|(\hat y^1_i-y^0_j)-(y^1_i-\hat y^0_j)| + |(\hat y^0_i-y^1_j)-(y^0_i-\hat y^1_j)|\) も得られ、こちらは処置群と対照群をまたいだ比較になる。どちらの最後の段も個人ごとの誤差の和になる。論文はこれを MSE 損失が最小化する量に当たるとし、MSE はアップリフトの順位から見ると中段より緩い上界しか抑えていないと論じる。なお、最後の段の式は絶対誤差の和の形で書かれている。

手法 2・3

応答の順位が入れ替わった組を罰し、さらに集団全体のアップリフトの並びをリストワイズに合わせる

応答の順位損失（RR）は 2 つの中間の上界を損失に置き換えたものである。群内の損失では、同じ群の 2 人について予測の大小が真の大小と食い違ったときだけ、差のずれの 2 乗を罰する。

\[ \mathcal{L}_{\text{wr-rank}}(i,j) = \begin{cases} 0, & (\hat y_i-\hat y_j)(y_i-y_j) \ge 0 \\ \big((\hat y_i-\hat y_j)-(y_i-y_j)\big)^2, & \text{otherwise} \end{cases} \]

群間の損失も同じ形で、処置群の \(i\) と対照群の \(j\) を組にして \((\hat y^1_i - y^0_j)\) と \((y^1_i - \hat y^0_j)\) を比べる。計算量を抑えるため、全ての組ではなく各群から一定数をサンプリングして計算する。

アップリフトの順位損失（UR）は ListNet の考え方で集団全体の並びを扱う。各人が 1 位に選ばれる確率を softmax で定め、真のアップリフトから作った確率と予測から作った確率の交差エントロピーを損失にする。真のアップリフトは観測できないので、論文は真の側の得点を \(\ln\tau\) と置いて正規化の定数を落とし、RCT では処置群と対照群の共変量の分布が同じであることを使って、観測された売上 \(y\) で書き直す。

\[ \mathcal{L}_{\text{lu-rank}} = -\frac{1}{|\mathcal D^t|}\sum_{\mathbf{x}\in\mathcal D^t} y\,\log\frac{e^{\hat\tau(\mathbf{x})}}{\sum_{\mathbf{x}'\in\mathcal D} e^{\hat\tau(\mathbf{x}')}} \;+\; \frac{1}{|\mathcal D^c|}\sum_{\mathbf{x}\in\mathcal D^c} y\,\log\frac{e^{\hat\tau(\mathbf{x})}}{\sum_{\mathbf{x}'\in\mathcal D} e^{\hat\tau(\mathbf{x}')}} \]

処置群で売上の大きい人の予測アップリフトは上に、対照群で売上の大きい人は下に押される。実装ではミニバッチの中で計算する。なお、得点を \(\ln\tau\) と置く段階は \(\tau\) が正であることを前提にした形になっている。最終的な学習目的は 3 つの損失を重みをつけずに足し、L2 正則化の項を加えたものである。

\[ \mathcal{L}_{\text{overall}} = \textcolor{#C2410C}{\mathcal{L}_{\mathrm{ZILN}}} + \textcolor{#1D4ED8}{\mathcal{L}_{\text{r-rank}}} + \textcolor{#1D4ED8}{\mathcal{L}_{\text{lu-rank}}} + \lambda\|\theta\|_2^2 \]
実験の設定

Hillstrom の 2 つのデータと Tencent の投資信託データで、4 つの順位指標を比べた

Hillstrom は 64,000 人への電子メール施策のデータで、配信後 2 週間の支払額（spend）を応答にする。男性向けメールと配信なしを組にした Hillstrom-Men と、女性向けメールと配信なしを組にした Hillstrom-Women を作っている。Product は Tencent FiT の投資信託の販売データで、500 万人以上、1,800 以上の特徴量（大半がカテゴリ変数）を含み、処置はインセンティブのクーポン、応答は投資信託の購入額である。いずれも学習・検証・テストに 60% / 10% / 30% で分け、5 つの乱数シードの平均を報告している。

比較対象は Causal Forest、S-Learner、T-Learner、TR、TAR、CFR（Wasserstein 版と MMD 版）、StableCFR、CITE、DragonNet である。RERUM はこのうち TAR、CFR の 2 種、DragonNet に組み込んだ。評価指標は AUUC と AUQC（いずれも「jointly, absolute」版を 100 区間で近似して正規化したもの）、ケンドールの順位相関 KRCC、上位 30% での処置群と対照群の平均売上の差 LIFT@30 である。

以下の数値は arXiv v2（2024 年 6 月 12 日）の本文と表による。KDD 2024 の掲載版（ACM Digital Library）の本文は自動取得できなかったため、照合していない。

実験の結果 1

どのモデルに組み込んでも、RERUM は AUUC を上げた

Table 1 では、RERUM を組み込んだ 4 つのモデルが、それぞれ元のモデルを 3 つのデータと 4 つの指標のすべてで上回っている。たとえば TAR に組み込んだ場合の AUUC の改善は、Hillstrom-Men で 11.45%、Hillstrom-Women で 10.82%、Product で 5.70% である。既存手法の中で最も良いものとの比較では、AUUC の最高値は Hillstrom-Men と Hillstrom-Women が RERUM（DragonNet）の 0.6721 と 0.6580、Product が RERUM（CFRwass）の 0.7563 だった。RERUM（DragonNet）の LIFT@30 は、3 つのデータの平均で 21.98% 改善している。

ただし、どの組でも最良の既存手法を上回るわけではない。Product では RERUM（TAR）の AUUC が 0.6863 で、CITE の 0.6976 を下回る。Hillstrom-Men の LIFT@30 では、RERUM（TAR）の 1.3477 と RERUM（CFRmmd）の 1.3015 が DragonNet の 1.3526 に届いていない。また Table 1 の太字は KRCC の Hillstrom-Men と Hillstrom-Women では RERUM（CFRmmd）についているが、値は RERUM（TAR）のほうが大きくなっている（0.1617 と 0.1806）。

実験の結果 2

3 つの部品はそれぞれ順位指標を押し上げ、ZILN は売上の回帰誤差も大きく下げた

Table 2 は元のモデルに UR、RR、ZILN の順で部品を足したときの変化である。DragonNet の Hillstrom-Men では、AUUC が 0.6028 から 0.6534（+UR）、0.6684（+UR+RR）、0.6721（RERUM）と上がる。論文は、どの部品を足しても 4 つの指標がある程度よくなると述べる。ただし表には例外もあり、Product の LIFT@30 は TAR+UR+RR の 1.0610 から RERUM（TAR）の 1.0247 に下がり、Product の KRCC は CFRmmd+UR の 0.3697 から CFRmmd+UR+RR の 0.3014 に下がっている。

付録では群内と群間の順位損失を 1 つずつ外している。どちらを外しても性能は下がり、群内の損失を外したときのほうが下がり幅がやや大きい（RERUM（TAR）の Hillstrom-Men の AUUC は 0.6299 から、群内を外すと 0.6203、群間を外すと 0.6228）。

回帰の精度は MAPE で比べている（Table 3）。MSE を ZILN に替えると、TAR の MAPE は Hillstrom-Men で 0.2142 から 0.0586 に、Product で 0.4429 から 0.1378 に下がった。順位損失を足すと MAPE はやや悪化する（RERUM（TAR）で 0.0667 と 0.1535）が、MSE で学習した元のモデルよりは小さい。論文は、順位損失の目的は回帰ではなく順位なので、この程度の悪化は許容できるとしている。バッチサイズとサンプル数への感度は図で示され、論文はどちらにも比較的頑健だと述べている。

実験の結果 3

Tencent FiT の 3 回のオンライン実験で、上位 2% の売上の差が平均 20.61% 大きくなった

オンライン実験の場面は Tencent FiT の資産運用事業での投資信託の販売で、処置は通知の赤い点（レッドポイント）の表示、応答は売上である。約 4 億人の利用者からモデルのアップリフト上位 2% を選び、その中を無作為に処置群と対照群に分けて、その後 1 か月の平均売上の差（売上の LIFT@2）を比べた。

比較相手は、論文が最先端とする既存のオンラインモデル（Base）と、それに RERUM を組み込んだモデルである。LIFT@2 は 3 回のキャンペーンで 24,566 → 26,826（+9.20%）、30,137 → 41,360（+37.24%）、21,971 → 25,361（+15.43%）となり、論文は平均の改善を 20.61% としている。さらに、RERUM によって運用資産（AUM）が毎月 4.3 億ドル増えたと報告している。表の数値の単位は書かれていない。

予算制約つきアップリフトの中での位置づけ

費用と予算は扱わず、売上の増分の順位を正しくすることに集中する

この論文が推定するのは、処置による売上の増分（CATE）\(\tau(\mathbf{x})\) である。クーポン代や通知のコストは学習目的にも評価にも入っておらず、利益ではなく売上を対象にしている。処置は二値で、複数の処置は今後の課題に挙げられている。

予算制約も扱っていない。ただし評価は上位 30%（LIFT@30）や上位 2%（オンライン実験）のように、介入する人数を先に決めて上位から選ぶ形になっている。一人あたりの費用が全員同じなら、ROI 順の割当て（ナップザック問題の連続緩和）はアップリフトの大きい順に選ぶことと一致する。この場合、論文が改善しようとしている「順位の正しさ」はそのまま割当ての良さにつながる（解説者の注）。

一方、クーポン代が人によって違うときや、購入したときにだけ費用がかかるときは、ROI 順は売上の増分の順と一致するとは限らない。RERUM の順位損失は \(\tau\) の並びを合わせるもので、費用で割った比の並びは学習しない。予算のもとで使うには、別に推定した費用と組み合わせる必要がある（解説者の注）。
