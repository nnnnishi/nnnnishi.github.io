Direct Heterogeneous Causal Learning for Resource Allocation Problems in Marketing

マーケティングの資源配分問題のための、異質な因果効果の直接学習

  • Hao ZhouMeituan, China
  • Shaoming LiMeituan, China
  • Guibin JiangMeituan, China
  • Jiaqi ZhengState Key Laboratory for Novel Software Technology, Nanjing University, China
  • Dong WangMeituan, China

予算の範囲で誰に施策を配るかを決めるとき、従来の二段階の方法は売上とコストへの効果を別々に予測し、その結果を割り算や最適化にかける。そのため予測の誤差が後段で膨らみやすく、予測精度を上げても割当てが良くなるとは限らない。この論文は並べ替えるだけで割当てが決まる量（決定因子）を最適化の側から取り出し、その量を損失関数で直接学習する。

背景

二段階の方法では、予測を改善しても割当てが良くなるとは限らない

マーケティングでは、値引きやクーポンのような施策が売上を増やす一方で、予算も消費する。そのため施策を配れる相手は一部に限られ、誰に配るかは資源配分問題として定式化される。既存研究の多くはこれを二段階の方法（two-phase methods）で解く。まず機械学習（ML）で処置ごとの反応やその増分を予測し、次にその予測を入力としてオペレーションズ・リサーチ（OR）の組合せ最適化を解く。

論文はこの方法の欠点を2つ挙げる。1つ目は予測結果に複数の量の組合せや複雑な演算を施してから解を得るので、予測パラメータの精度が上がっても最終的な解が良くなるとは限らないこと。2つ目は予測の誤差が OR の側で考慮されず、演算を重ねるうちに誤差が蓄積することである。論文によれば、このため理論上は最適な OR のアルゴリズムが実際には最適にならず、場面によってはヒューリスティックな方策にも劣る。

考え方

並べ替えだけで解が決まる量を、そのまま学習の目標にする

論文は、組合せ最適化のアルゴリズムが並べ替えか比較だけで最終的な解を出せるとき、その基準となる量を決定因子（decision factor）と呼ぶ。決定因子を ML の学習目標にすれば、OR の側で予測結果に演算を重ねずに済む。モデルが決定因子をどれだけ正しく順位づけるかがそのまま解の質を決めるので、モデルを改善すれば解も改善される。

二値の処置で具体的に見る。個人 \(i\) の特徴を \(x_i\) とし、処置による売上 \(Y^r\) とコスト \(Y^c\) の条件付き平均処置効果（CATE）を次のように書く。

\[ \tau^{*}(x_i) = E\bigl[\,Y^{*}(1) - Y^{*}(0) \mid X = x_i\,\bigr], \qquad * \in \{r, c\} \]

多くの施策は反応を増やすとして、論文は \(\tau^r(x_i) > 0,\ \tau^c(x_i) > 0\) とおく。予算 \(B\) のもとで売上の増分の合計を最大にする問題（BTAP）は次のとおりである。

\[ \max_{z}\ \sum_i z_i\,\tau^r(x_i) \quad \text{s.t.}\ \ \sum_i z_i\,\tau^c(x_i) \le B,\ \ z_i \in \{0,1\} \]

これは0/1ナップサック問題と同値で NP 困難だが、\(\tau^r(x_i)/\tau^c(x_i)\) の大きい順に並べ、予算を超えるまで配る貪欲法（論文の Algorithm 1）で良い近似解が得られる。この貪欲法の決定因子が個人の ROI、つまり \(\tau^r(x_i)/\tau^c(x_i)\) である。処置コストがないか全員で同じ場合（例：プッシュ通知）は、決定因子は \(\tau^r(x_i)\) だけになる。

手法

DRP の損失は凸で、収束点では出力が \(\tau^r/\tau^c\) に一致する

ROI は2つの量の比なので、既存研究の多くは2つのモデルの予測を組み合わせて求める。論文は組合せの演算で誤差が拡大しうると指摘し、ROI を1つのモデルで直接予測する DRP（Direct ROI Prediction）を提案する。RCT で集めたデータ \((x_i, t_i, y^r_i, y^c_i)\) を使い、処置群と対照群の件数を \(N_1, N_0\) とする。任意の ML モデルの出力 \(s_i = \hbar(x_i)\) をシグモイドに通した \(q_i = \sigma(s_i)\) について、損失を次のように置く。

\[ \begin{aligned} L(s) = -\Bigl[ &\frac{1}{N_1}\sum_{i \mid t_i = 1}\Bigl(y^r_i \ln\frac{q_i}{1-q_i} + y^c_i \ln(1-q_i)\Bigr) \\ - &\frac{1}{N_0}\sum_{i \mid t_i = 0}\Bigl(y^r_i \ln\frac{q_i}{1-q_i} + y^c_i \ln(1-q_i)\Bigr)\Bigr] \end{aligned} \]

RCT では処置の割当てが潜在的結果と独立なので、この損失は \(-\frac{1}{N}\sum_i\bigl[\tau^r(x_i)\ln\frac{q_i}{1-q_i} + \tau^c(x_i)\ln(1-q_i)\bigr]\) と書き直せる（論文 Appendix B）。\(s_i\) での1階微分は \(-\frac{1}{N}\bigl(\tau^r(x_i) - q_i\,\tau^c(x_i)\bigr)\)、2階微分は \(\frac{1}{N}q_i(1-q_i)\,\tau^c(x_i) > 0\) なので損失は凸であり、微分が0になる点で \(q_i = \tau^r(x_i)/\tau^c(x_i)\) となる。\(\sigma\) は単調増加なので、\(s_i\) の順位がそのまま ROI の順位になる。

\(q_i\) は (0,1) の値しかとらないので、ROI もこの範囲になければ最小点は存在しない。論文は、割り算で ROI の分散が大きくなりやすい（特に \(\tau^c\) が小さいとき）ことも理由に挙げ、\(Y^r\) か \(Y^c\) をスケーリングと切り詰めで調整して ROI を (0,1) に収める。下の図で \(\tau^r\) と \(\tau^c\) を動かすと、最小点の位置が \(\tau^r/\tau^c\) に沿って動くことと、\(\tau^r \ge \tau^c\) では最小点が消えることを確かめられる。

コストを考えない場合についても、論文は同じ考え方で \(\tau^r(x_i)\) を直接学習する DUM（direct uplift modeling）を提案している。こちらはソフトマックスで正規化した \(q_i\) を使い、収束点で \(q_i = \tau^r(x_i)/\sum_j \tau^r(x_j)\) となる。また、ROI の順位を直接学習する既存手法 Direct Rank（Du et al., 2019）について、論文は Appendix E で、収束したと仮定するとすべての個人の ROI が等しくなければならないことを導き、その損失が安定な極値点に収束しないことを示している。

多値の処置

多値の処置では、ラグランジュ乗数を含まない限界 ROI を学習する

次に、値引き額のように段階のある処置 \(j \in \{1, \dots, L\}\) から1人に1つを選ぶ問題（MTBAP）を考える。個人 \(i\) が処置 \(j\) を受けたときの売上とコストを \(r_{ij}, c_{ij}\) とし、段階が上がるほど両方とも大きくなるとする。

\[ \begin{aligned} &\max_{z}\ \sum_{ij} z_{ij}\,r_{ij} \\ &\text{s.t.}\ \ \sum_{ij} z_{ij}\,c_{ij} \le B,\ \ \sum_j z_{ij} = 1,\ \ z_{ij} \in \{0,1\} \end{aligned} \]

これは多重選択ナップサック問題で、既存研究はラグランジュ双対で解くことが多い。最適な乗数 \(\alpha^*\) が決まれば、各個人に \(r_{ij} - \alpha^* c_{ij}\) が最大になる処置を選ぶ。この \(r_{ij} - \alpha^* c_{ij}\) も決定因子だが、\(\alpha^*\) は予算 \(B\) に依存し、学習データに一度も現れていない値が将来の施策で使われる可能性がある。論文は、あらゆる \(\alpha^*\) について直接予測するのは難しく現実的でないとして、これを学習目標にしない。

代わりに論文は限界効用逓減の法則（仮定1）のもとで、\(\alpha\) を含まない限界 ROI を使う。

\[ \ell_{ij} = \frac{r_{i,j+1} - r_{ij}}{c_{i,j+1} - c_{ij}}, \qquad \ell_{ij} \le \ell_{i,j-1} \]

双対法で選ばれる処置 \(j^*\) は \(\ell_{ij^*} \le \alpha \le \ell_{i,j^*-1}\) を満たすので、\(\ell_{ij}\) と \(\alpha\) を比べるだけで同じ解が得られる（Algorithm 2、定理3）。\(\ell_{ij}\) を直接学習する損失も示されており、収束点では \(q_{ij} = \ell_{ij}/2\) となる（Appendix D）。この \(\ell_{ij}\) の予測と Algorithm 2 を組み合わせた方法が DPM である。評価のために論文は AUCC を多値の処置に広げた指標 MT-AUCC も提案している。モデルの曲線の下の面積 \(A_M\) とランダムな基準の面積 \(A_R\) から \(A_M/2A_R\) と定義し、値を (0,1] に収める。

実験

オフライン実験でも A/B テストでも、提案法が比較手法を上回った

オフライン実験では2つの RCT データを使う。CRITEO-UPLIFT v2（1390万件、特徴量12個）では、ROI を比べるために訪問ラベルをコスト、コンバージョンラベルを売上とみなす。Marketing data は Meituan の値引き施策 Money Off で4週間行った RCT（410万件、特徴量75個）で、処置は値引き額 \(T \in \{0, 1, \dots, 6\}\)、応答は日次のコストと注文数である。二値の問題では \(T = 0\) を対照群、\(T > 0\) を処置群とする。各データ点は20回の実行から計算されている。

コストを考える二値の問題（AUCC）では、DRP が両方のデータで TPM-SL と Direct Rank を上回った。多値の問題（MT-AUCC）では、DPM が TPM-SL と TPM-CF を上回った。論文は提案モデルのばらつきが小さいことも挙げ、直接学習によって安定な極値点に収束するためだと説明している。コストを考えない問題でも、DUM の AUUC は CRITEO-UPLIFT v2 で 0.8749、Marketing data で 0.8077 となり、S-Learner、X-Learner、Causal Forest を上回った。

オンラインでは Meituan の Money Off で DPM を4週間運用した。31万店舗を G-DPM、G-TPM（TPM-CF）、G-Control（値引きなし）の3群にランダムに分け、群分けは毎週やり直した。予算の範囲で各店舗の値引き額を毎日決め、注文数と GMV の最大化を目指す。G-Control に対する増分で比べると、DPM は毎週 TPM-CF より増分注文数が多く、増分 GMV でも劣らなかった。平均すると増分注文数は14.3%、GMV は13.6%伸びたと報告されている。

予算制約つきアップリフトの中での位置づけ

DRP は、増分コストが人ごとに違う二値の処置で、ROI の順位を1つのモデルで学習する

  • 推定するもの：売上の増分とコストの増分の比 \(\tau^r(x)/\tau^c(x)\)。順位は \(s_i\) から、値は \(q_i\) から得る（値は ROI を (0,1) に収めたあとの尺度）。
  • コストの仮定：コストは処置ごとの定数ではなく、結果として観測される \(Y^c\) で、その増分 \(\tau^c(x)\) は人ごとに違ってよい。\(\tau^r > 0,\ \tau^c > 0\) を仮定し、ROI を (0,1) に収める前処理が要る。
  • 処置：二値（DRP、コストを考えない場合は DUM）と、段階に順序がある多値（DPM）。多値では限界効用逓減を仮定する。
  • データ：RCT データを前提とする。損失の書き換えは割当てと潜在的結果の独立性と SUTVA に依存している。観察データで傾向スコアを使う拡張は、論文では扱っていない。
  • 割当て：二値では ROI の順に配る貪欲法、多値では \(\ell_{ij}\) と \(\alpha\) を比べる二分探索（Algorithm 2）を使う。

購買したときだけ定額 \(C\) の報酬を払う施策に当てはめると、次のようになる（解説者による対応づけで、論文はこの設定を扱っていない）。対照群のコストは0なので \(\tau^c(x) = C\cdot E[Y(1) \mid x]\) となり、DRP の決定因子 \(\tau^r/\tau^c\) は \(E[S(1) - S(0) \mid x]\,/\,(C\cdot E[Y(1) \mid x])\) と同じ順位の基準になる。\(Y^c\) として「処置群で購買したら \(C\)、それ以外は0」を与えれば、DRP の損失の形はそのまま使える。ただし論文の実験はこの設定を含まず、ROI を (0,1) に収める調整も別に必要になる。

まとめ

最適化が並べ替えに使う量を学習すれば、予測の改善が割当ての改善につながる

論文は、資源配分の解が並べ替えや比較だけで決まる量（決定因子）を最適化の側から取り出し、それを学習目標にする方法を提案した。二値の処置では ROI を直接学習する DRP、多値の処置では限界 ROI を直接学習して Algorithm 2 で配る DPM を示し、大規模なオフライン実験とオンライン A/B テストで有効性を確かめている。今後の課題として論文は、複数の施策が同時に行われて互いに影響し合う場面を挙げ、そこで決定因子を導いて直接学習するのはより難しいと述べている。
